Make visual proof harnesses validate the run’s capture contract before opening a page: exact browser/backend, viewport, device pixel ratio, mobile/touch emulation, date and feed hash. During Plan 84, independent handoff captures drifted from DPR2 to DPR1/DPR3 and fetched different feed bytes despite a written contract; the manager rejected their use as fixed comparisons and requested corrected evidence. Shared Vite dependency caches also caused an invalid React diagnostic between worktrees. Give each development/test worktree its own optimized-dependency cache, retain failed attempts, and use one representative live picture plus composited contrast proof before running a broad capture loop. A numerical contrast pass alone accepted an oversized tint that visually erased the planet; live image review caught it. Software drawing measurements must explicitly say they compare relative cost, not native phone performance.
