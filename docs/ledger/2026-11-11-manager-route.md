The orchestrate skill gave the manager's model one sentence: the strongest class for a release, a cross-repository run or a deadline, otherwise a normal one. Plan 48's Phase 1 ran under a normal-route manager and showed the middle case that sentence missed: it merged a stale `main`, verified a merge without one of the named tests, and could not do the taste and review rows itself. The skill now treats the manager's route as its own decision, with one row each for N (works through a task list), X (iterates, wrangles and knows when to escalate), S (correctness across a costly run) and T (refinement), judged by the manager's own work and recorded on the plan's Run start line.
