Plans said "one round at the end", but lanes ran an Astra review on most cards: Plan 88's cards wrote "one independent review" into their proof column (TE-2, an N card), Plan 77's tooling cards SL-6 and SL-7 asked for independent reviews, and the run contract sent any bounded fix over about 500 lines or touching a shared contract to the high-judgment role, which managers read as "review every commit-path change". Added a per-card rule to the run contract (high-judgment review per card only for S cards, integrity or contract changes, or code already judged unsound; everything else waits for the final round), replaced the size trigger, and told the plan skill that a card's proof is evidence, never a review.
