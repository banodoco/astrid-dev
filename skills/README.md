# Astrid development skills

Use the entrypoint matching the work:

- [Astrid dev](astrid-dev/SKILL.md): orientation, repository ownership, pin order, and workflow routing.
- [Plan](astrid-dev-plan/SKILL.md): prior art and scope agreement for a new project or materially new scope.
- [Iterate](astrid-dev-iterate/SKILL.md): one implementation/debug/focused-proof repair loop; returns a feature candidate.
- [Release](astrid-dev-release/SKILL.md): integrated candidate review and explicitly authorized promotion/publication.

The [shared run contract](astrid-dev-shared/run-contract.md), [run template](astrid-dev-shared/templates/run.yaml), and concise [manager](astrid-dev-shared/roles/manager.md) and [advisor](astrid-dev-shared/roles/advisor.md) references centralize policy and role boundaries. No separate worker-execution skill exists: implementation and repair belong to Iterate. These installed skills are self-contained through sibling links; consult the active working repository for its own instructions and plans.
