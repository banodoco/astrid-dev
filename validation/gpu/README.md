# GPU validation records

One record per run of [full GPU validation](../../skills/astrid-dev-gpu-validate/SKILL.md), named `<YYYY-MM-DD>-<short-sha>.md` after the run date and the Agent revision under test. Each holds the revisions, pods and GPU, a pass or fail per cell, spend, and the pod census before and after. Records are add-only: a re-run gets a new file.
