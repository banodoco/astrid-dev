# CI-001 — Agents don't yet reliably learn from creative work

**Aspiration:** [An ecosystem of wisdom grounded in real work](../pillars/compounding-intelligence.md#an-ecosystem-of-wisdom-grounded-in-real-work) (primary) · [Explicit permissions and privacy](../principles/in-the-creators-control.md#explicit-permissions-and-privacy) (supporting) · **Assessment:** Open, source assessment (2026-11-06).

## Desired state

An agent routinely uses applicable earlier lessons **before** work, captures truthfully observed success or failure **during/after** work, learns within a user-owned private knowledge scope and can propose sanitized contributions to others with explicit permission.

## Current state

Astrid Agent has executable creative tools and Runtime task/artifact records. Banodoco Hivemind has an evidence-bearing read/contribution system. The [source map](../../plans/22-hivemind-protocol/inputs.md) **does not establish a complete private/local → community → later-agent learning loop**.

## Gap

Contextual retrieval, actual run-to-knowledge capture, safe private retention, consented contributions and proven benefits to a second agent session are not yet integrated end to end.

## Closure evidence

Two real agent sessions: the first retrieves applicable knowledge and produces an observed, locally retained result; a subsequent session demonstrably uses that finding. Optional contribution retains provenance and only shares approved, sanitized information. Compare against raw search/no knowledge, including staleness and denial paths.
