# Tasks — Astrid Cloud generation, phase 1

[Plan](plan.md) · [Inputs](inputs.md)

**Critical path:** A1 → A2 → A4 → A5 → A7 → A9 → R. A6 runs in parallel after A1, A3 after A2, and A8 after A7. There are no edge functions: Supabase is Auth, Postgres and Storage, and every endpoint is in the one Astrid Cloud service. Nothing touches the Banodoco project, Stripe live mode or paid providers before the owner's go on D2 and D5 and the budget.
