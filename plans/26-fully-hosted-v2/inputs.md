# Plan 26 — source inputs and open decisions

**Dependency:** [Plan 25](../25-cloud-assist-v1/plan.md) must provide proven remote execution/artifact contracts before hosted adoption. Existing Astrid App, Runtime and project/timeline schema are source of truth for the current local experience. Do not assume a cloud database exists merely because a cloud inference route exists.

**Unresolved:** hosted database, file/object storage provider, identity provider, tenancy model, data residency, security and privacy policy, storage/backups, cloud execution costs, collaboration scope, exports/migration/versioning and incident recovery. Need owner-approved plan and verified source map before choosing any provider.

**No claims of current delivery:** the hosted edition is a separate proposed stage. The test is a genuinely cloud-owned project and files, not a browser front end pointing at a local database.
