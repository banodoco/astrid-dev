Before each dispatch the manager records the actual base, dependency revisions, exact commands, task authority, and the current tests/fixtures invalidated by that card. Use public git at verified pinned revisions for cross-repo fixtures, never private data or archive downloads; record the hashes. Agent workers call `bash scripts/worker-env/agent-setup.sh` and `bash scripts/worker-env/agent-pytest.sh -q <named selectors>` from Agent root; Runtime workers call `bash scripts/worker-env/runtime-setup.sh` and `bash scripts/worker-env/runtime-pytest.sh -q <named selectors>` from Runtime root (copy the canonical [env scripts](../../env/README.md) into the product repository if missing). App workers use `bash scripts/worker-env/app-test.sh <named vitest files>` after copying the new canonical script into App, from the App root. Exit 3 is environment failure. The live proof needs an explicit safe local stack and cannot be replaced by a cloud unit test.
