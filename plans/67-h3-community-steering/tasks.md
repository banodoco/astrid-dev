## Speech on a still master, end to end

This is the owner's example, and the target for CS-8's first recipe:

| Item | Lever and family | Mechanism |
| --- | --- | --- |
| exact start still at frame 0 | place, Output | latent and ownership mask; composition restores it |
| voice sample | reference, Context | untimed rows, `<Audio 1>` |
| silent 0–2 s, "the line" 2–4 s, reaction 4–6 s | timed prompt, Context (CS-2) | prompt text in H3's timed shot format |
| optional speech-like cue silent at 0–2, active at 2–4, silent at 4–6 | audio guide at frame 0 with `phase: [0, 0.2]`, made by the curve tool (CS-3, CS-4) | timed rows through `NKDMiniMaxGuides` |

All of it is soft except the start still. The line's timing is biased, not guaranteed; the live test judges it.
