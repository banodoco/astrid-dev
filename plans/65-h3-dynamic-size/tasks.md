**DS-4 geometry and handoff.** Use the D2 decision in the request and spec. With the recommended pixel form, `mask.canvas: [w,h]` declares the rectangle's authored working canvas, implicitly 1024×576. Validate the half-open box within that canvas. Scale its left/right and top/bottom edges independently by the two target/authored ratios. For each edge use `ceil(edge - 0.5)` and clip the resulting index to the target extent. This preserves existing pixel-center inclusion and rejects invalid input boxes before rounding. A still's own raster defines its authored canvas. Validate grayscale, polarity and binary values (or apply the explicit existing threshold) before nearest-neighbor sampling. These selectors describe the complete prepared view, including fit bars. A selector supplied in camera coordinates must first be authored against the cropped or padded view.

The masked compiler owns the artifact. Rasterize each static selector once at effective size, combine compatible members by pixel maximum, and use the existing bounded-frame encoding for a partial interval. Bind those bytes to generation. In build state persist a relocatable mapping from each source occurrence and edit ordinal to its frame interval, target size, member digest and managed artifact member, including the union/bounded binding shared by compatible edits. Verify digests on load and pass the mapping through `after_outputs` into composition. Paste-back reads the identified bytes and intervals directly. Remove rectangle reconstruction, original-static-asset fallback and the second resize from this path. Keep current same-interval/strength/seed/reference union admission. Register each validated moving mask as a pass-through row in that same mapping, with its managed bytes, digest, dimensions and interval. Composition uses one mask reader for static and moving entries. Remove the separate moving-asset lookup and keep codec and clock checks at preflight. Keep lossless, source-size, binary-frame, frame-count and clock preflight for moving masks and existing refusal of combined moving masks. Preserve legacy default compiler file/digest fixtures by carrying the compositor mapping in build state outside the emitted default bundle.

Use a non-16:9 source with a small off-center landmark, test crop and letterbox at 768×448, and a 1024×576 authored mask at 512×288. Compare decoded output across frames to the **prepared source** outside the resolved permissions and across whole frames before/after the edit. Change candidate pixels both inside and outside to detect incorrect permission. Test adjacent fractional edges, two-region union and a frame-varying moving mask whose original asset is unavailable after handoff. Verify paste-back follows the mapped bytes frame by frame. For standalone `media mask --preview-on`, retain explicit `--size` as target, defaulting to the stored raster when omitted. Preview uses the existing fill transform on raw input. To preview fit, supply the letterboxed prepared source at its working aspect. Share working-canvas mask geometry and conform's fill transform. Render a temporary resolved overlay and verify stored bytes and recipe remain identical after preview.
