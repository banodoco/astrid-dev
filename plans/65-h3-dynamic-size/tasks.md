## DS-3 detail

**Rectangle masks.**
- A box may state `mask.canvas: [w, h]`, its authored canvas. Without it, the canvas is 1024×576, which is what every existing box was drawn on.
- Coordinates are pixel-edge coordinates with a top-left origin. A box `[x, y, width, height]` covers the half-open area `[x, x+width) × [y, y+height)`. Reject non-finite values, zero or negative width or height, and a box not wholly inside its canvas, before scaling.
- Validate the half-open box inside its canvas, then scale the left/right edges by `target_w / canvas_w` and the top/bottom edges by `target_h / canvas_h`.
- Round each scaled edge with `ceil(edge - 0.5)` (D3: an exact half rounds down) and clip it to the target. This keeps today's pixel-centre inclusion. The fixture oracle states the tie rule.
- Coordinates describe the prepared view, fit bars included.

**Still-image masks.**
- The still's own pixel size is its canvas.
- Decode it to grayscale, check it's binary (or apply the existing explicit threshold), then resample it to the target with nearest-neighbour.

**The handoff.**
- The masked compiler rasterizes each static mask once at the target size, combines compatible masks by pixel maximum, and uses the existing bounded-frame encoding for a partial window.
- **Two masks, not one shared file** ([Permission and strength](../66-h3-composable-core/tasks.md#functional-additions-two-masks)). Rasterize each occurrence's binary permission once, and union the active permissions for paste-back. Derive a separate time×space sampler mask from the maximum active strength times support (outside = 0, inside = 1). Bind the sampler mask to generation and the permission mask to composition, through the existing managed artifact handoff. Never blend candidate pixels a second time with a grey weighted mask.
- A nonempty grant whose effective footprint vanishes on the model's grid fails, naming the grant.
- **Verifier.** Record the prepared binary mask with its managed artifact identity and its derivation from the input. Verify composition and post-mux evidence against that raster and each occurrence's own prepared offset; a resized still mask may legitimately differ from the input hash. Test resized still masks, moved scratch directories, and two sources with different offsets.
- Composition reads the file. It no longer redraws rectangles, falls back to the original asset or resizes a second time.
- Union rules follow Plan 64 SR-1: regions in one pass share one seed and one reference set, and may differ in interval and strength. Keep every existing refusal: polarity, threshold, invalid box, and moving-mask codec, size, clock and lossless rules.

**Fixtures.**
- A non-16:9 source with a small off-centre landmark, cropped and letterboxed at 768×448.
- A 1024×576 authored box used at 512×288.
- Adjacent fractional edges, and a two-region union.
- Overlapping 0.25 and 0.75 grants at different times; a tiny mouth between sample centres; a moving red-channel mask.
- Compare decoded output with the prepared source outside the mask. Change candidate pixels both inside and outside, so a wrong mask fails.
- For `media mask --preview-on`, `--size` stays the target (default: the stored raster). The stored bytes and recipe are identical after a preview.
