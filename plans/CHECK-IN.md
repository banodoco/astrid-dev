# Focused check-in notes

This is a reusable checklist, not an active schedule. The existing advisor and orchestrator automations remain paused. Use it only if the owner has started execution and requested a check-in.

- Read the current README queue and the active Megado run status; do not duplicate their status or counters here.
- Review only the current blocker or changed acceptance boundary. Ask for exact source/test evidence, including whether a check is unexecuted, failed, cancelled, or passed.
- Check that independent eligible work is not waiting on an unnecessary whole-project gate; check that Terra/Sol execution leads have Luna helper support.
- Confirm only scoped feature tests ran. Do not launch broad suites, new monitoring, or a new approval loop.
- Record durable conclusions in the existing run or plan, and report only material progress, regression, or a real authority conflict.
