## The finding

CodeQL's annotation on the completion pull request (high severity): `scripts/skill_builder.py` lines 23 to 23, "Inefficient regular expression: this part of the regular expression may cause exponential backtracking on strings starting with `[](` and containing many repetitions of `<>`."

The pattern at the head is:

```text
_LINK = re.compile(r"(!?\[[^\]\n]*\])\(((?:\\[^\n]|<[^>\n]*>|\((?:\\[^\n]|[^()\\\n])*\)|[^()\\\n])+?)\)")
```

Its repeated group has alternatives that can match the same text: `<[^>\n]*>` (an angle-bracketed destination) and the final character class `[^()\\\n]`, which also matches `<` and `>`. So `<>` can be read two ways, and a long run of `<>` with no closing `)` multiplies the readings.

## Required change

Make the alternatives of the repeated group disjoint, so each position can be consumed in only one way, without changing what the pattern matches on valid input. The orchestrator's suggested shape (you may choose another that satisfies the tests): keep `\\[^\n]`, keep `<[^>\n]*>`, keep the parenthesised group, and change the final class so it cannot start an angle pair: replace `[^()\\\n]` with `[^()\\<\n]`, and add one alternative for a `<` that does not begin a complete angle pair on the line, `<(?![^>\n]*>)`. The angle alternative needs a `>` ahead on the same line and the new one forbids it, so they cannot both match at one position. Check that the other repeated groups are also disjoint (the inner group of the parenthesised alternative uses `\\[^\n]` and `[^()\\\n]`, which already exclude each other).

## Tests (new, in `scripts/test_skill_builder.py`, in the existing style)

- Bounded time: build the string `"[](" + "<>" * 5000` (no closing parenthesis) and a second with `"<>"` replaced by `"<"` and by `"(<>"`; assert that applying `_LINK.search` (or the function that uses it) finishes in under one second each. If a time assertion is judged flaky, assert instead on a small step count by running the same input at 20 and 40 repetitions and checking that the work does not grow exponentially (time for 40 less than 20 times the time for 20, with a generous floor); explain the choice in the early STATUS.
- Equivalence on valid input: for a table of at least ten link destinations, including plain, with a title, angle-bracketed with spaces, angle-bracketed containing parentheses, nested parentheses, an escaped parenthesis, an image link, and a destination containing a lone `<` or `>`, assert that `_LINK` matches exactly what the old pattern matched (copy the old pattern into the test as a constant and compare `match.group(0)` and groups for each case).
- Existing tests are untouched and must keep passing.
