## Method

Pair each document using `evidence/cutover-map-a.md` and `cutover-map-b.md`. Read the `skills/` source at the `main` SHA those maps record, and the `agent/` file on the project head. A **consequential rule** is any sentence that says what must, must not, may only, or needs someone's go: permissions and authority, review and rounds, routing and models, proof and test integrity, merging and branches, escalation, liveness. Ignore examples, wording and ordering.

The audit file has one table per document: `rule (quoted, ≤ 25 words)` | `source line` | `agent/ line that carries it` | `status`, where status is `kept`, `restored` (you added it back in this PR) or `moved` (it now lives in another named `agent/` document, linked from this one). Finish with one count line per document (rules found, kept, restored, moved). A rule you believe was deliberately dropped is not yours to drop: mark it `restored` and say why you think it may be obsolete, and the orchestrator rules.
