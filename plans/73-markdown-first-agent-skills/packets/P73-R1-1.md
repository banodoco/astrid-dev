## The finding (from R, verbatim in substance)

`scripts/agent_documents.py` validates an opted-in stem only against the lowercase kebab-case expression, then `AgentDocument.skill_name` prepends `astrid-dev-` (11 characters). `scripts/skill_builder.py` emits that complete name with no length check, and the stale/consistency check compares against the same expectation, so nothing catches it. A source named `agent/shared/workstreams/check-generated-workstream-and-shared-policy-discovery.md` (54-character stem) emits a 65-character name, over the specification's 64-character limit. See [R's verdict](https://github.com/banodoco/astrid-dev/issues/1882#issuecomment-7166533493).

## Required behaviour

- Reject an opted-in document whose complete generated name exceeds 64 characters, with a message that names the file, the generated name, its length and the limit, before the builder publishes any output. Refuse at one place the check and the builder both reach (the document parser or validator), so there is one code path, not two copies of the rule.
- Keep the filename-derived identity. Do not truncate, hash or alias a name.
- A document that does not opt in (`skill: false` or absent) is not affected, however long its filename.
- Tests (new, in the existing test files and style): a 53-character stem (64-character name) is accepted and builds; a 54-character stem (65-character name) is refused by the validator and by `skills build`, with the message above; on refusal an already built `.generated/skills` tree is byte-for-byte unchanged and nothing new is created; a long filename without `skill: true` is accepted.
- In `docs/extending.md`: state the effective limit for the filename stem (53 characters, because the 11-character `astrid-dev-` prefix leaves 53 of the 64), and delete the sentence that still tells the author to add a navigation link for a shared workstream by hand (the guide's later paragraph and `agent/README.md` correctly say the shared-workstream index is generated automatically and must not be hand-edited). Change nothing else in the guide.
