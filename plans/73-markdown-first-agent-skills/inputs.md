[Plan 48](../48-one-record-model/plan.md) established the general checks/views layer; [Plan 51](../51-astrid-dev-clean-up/plan.md) consolidated rules and vocabulary. [`scripts/views.py`](../../scripts/views.py) generates role indexes and shared blocks. [`sync.sh`](../../sync.sh) installs flat symlinks from authored package directories while `python3 scripts/astrid_dev.py sync` regenerates unrelated documentation views. [`scripts/test_skill_installer.py`](../../scripts/test_skill_installer.py) pins the old installer behavior; [`scripts/test_workstreams.py`](../../scripts/test_workstreams.py) pins the two formats and generated indexes. The [documentation workflow](../../.github/workflows/docs.yml) has guarded generated-target writeback, not a generic skill installer. Existing [Plan skill](../../skills/shared/workstreams/astrid-dev-plan/SKILL.md) governs this proposal.

**Approach:** Create a new project rather than reopen completed Plan 51: retain its one-home-per-rule policy and the reusable parser/view infrastructure, but eliminate authored skill packages and two document formats. Generate package directories from source frontmatter; derive names from filenames, package only necessary references, and replace the installer/validator assumptions. Keep role and shared-workstream ownership clear without introducing a new framework or database. The [CA-005 gap](../../vision/gaps/CA-005-parallel-contribution.md) already measures simpler contribution and extensions; this project supplies another scoped part of that outcome but not the concurrent-contributor proof.

**Challenge:** Not needed — A separate pre-greenlight critique no longer gates this owner-authorized start. The explicit RS1 high-judgment package-contract review and R integrated review remain mandatory before the dependent phases and final merge; no independent critique has yet been performed. The manager must report a precise blocker if no independent reviewer can be commissioned.

**Proof and limits:** Proposed, not run. Prove identical substantive role/workstream obligations by source-to-target audit; a deterministic skill builder, safe installer, correct relative references, full documentation CI and real cold-start selection in the currently supported Claude/Codex installations. Test negative cases and stale/foreign paths. Do not infer Windows symlink compatibility, portable standalone archives, or CA-005's ten-contributor outcome from an ordinary Unix build.

**Review rounds:** Recommend one review stop (`RS1`, max one round) on source metadata, reference/packaging contract and refusal cases, because every later migration task builds on it, and one final integrated review (`R`, max one round) before proposing installation/cutover. Pending owner confirmation. No extra automatic approval gates.
