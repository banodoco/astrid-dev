**Give this document, and only this document, to a new eligible agent.** An independent proctor supplies an *exact SHA*, an isolated checkout and permission to use only disposable directories. This task does not approve a D5 migration, a merge or an installation into a real user profile.

## Assignment

You have a clean, disposable checkout of `banodoco/astrid-dev` at the exact commit SHA supplied by the proctor.

Read `agent/README.md`, follow its ordinary authoring instructions and the relevant linked documentation, and create **one independently callable new shared workstream** of your own choice. Use the repository's documented workflow to verify it, make its generated skill discoverable in the disposable client environment provided to you, and demonstrate that the instructions can actually be loaded and used.

Then return the workstream to a non-skill Markdown source without deleting the source or altering other installed skills. Preserve all original skill sources and any unrelated entries. Do not modify branches, push, merge, use paid infrastructure or access a real user's skill directories.

## What to return

Report the chosen source path, generated skill name, exact checkout SHA, client/environment you actually used, your commands and exits, evidence of both discovery and instruction loading, observed cleanup, and any confusing, missing or contradictory guidance. Clearly distinguish what you personally executed from what you could not verify. Return logs or file references inside the disposable environment.

If a client or capability is unavailable, record **NO-RESULT**, not PASS; continue with everything else that can genuinely be tested.

## Boundaries

You are not authorized to rewrite active release or plan instructions, delete `skills/`, change canonical task statuses, enable permanent automations or perform an MS-7/MS-9 cutover. Ask the proctor for access to a required disposable resource, not implementation hints. Your findings are a candidate for independent evaluation, not acceptance by assertion.
