## RH-1 in detail

**Why first.** On 16 November 2026 the Morpheus pilot's dry run was refused: the Matrix media is 23.976 fps and 1920×800, and the pack accepts only exactly 24 fps and 1024×576, then tells the caller to run an ffmpeg command that would stretch the picture. Version 1 continuation also needs the source range to start at zero, and every asset must be a local file.

**Outcome.** A request names its source as a media handle (`sha256:…`, `run:<id>/<port>#n` or `ref:…`, exactly as `astrid/sdk/media_handles.py` defines them) or, as today, an asset-map name; gives a source range anywhere in that media; and may state `fit: fill` or `fit: fit` (default per D4). Prepare cuts the range, conforms it to 24 fps constant and 1024×576 without changing the picture's shape, aligns sound and picture length, and records in the preparation manifest the source digest, range, fit, what was done and the prepared file's digest. The strict check stays, applied to the prepared file, so the graph still receives only exact input. A mask or reference may be a handle too. Local paths keep working.

**Contract card (re-check against the code at dispatch; Plan 59's H3 pilot track may already have changed part of this).** Made untrue, and changed from "refused" to "conformed, recorded, and the prepared file passes the strict check": `tests/packs/h3_av/test_source_rate_prepare.py::test_23976_source_is_rejected_on_every_source_backed_route`, `::test_wrong_size_source_is_rejected_with_conform_command`, `::test_vfr_source_is_rejected`, `::test_audio_duration_mismatch_still_fails_preflight`. Removed: `SOURCE_AV_CONFORM_COMMAND` and its hint (`shared/prepare.py:159-160`). Changed: the "must start at zero" refusal (`shared/timing.py:153-154`) no longer reaches the caller, because prepare hands the graph a clip that starts at zero; any test pinning that message is listed before it is touched. Unchanged: `::test_conformed_24fps_source_passes_on_every_source_backed_route`, `::test_missing_ffprobe_has_coded_error`, `::test_source_free_generate_never_probes_a_source`.
