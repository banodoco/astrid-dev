## RH-1 in detail

**Why first.** On 16 November 2026 the Morpheus pilot's dry run was refused: the Matrix media is 23.976 fps and 1920×800, and the pack accepts only exactly 24 fps and 1024×576, then tells the caller to run an ffmpeg command that would stretch the picture. Version 1 continuation also needs the source range to start at zero, and every asset must be a local file.

**Contract.**

1. *Naming an input.* In a version 1 request, `source.asset`, a reference's `asset` and a mask's `mask_asset` may each be a media handle in the existing forms (`sha256:…`, `run:<id>[/<port>][#n]`, `ref:…`). Handles are resolved at admission by `resolve_media_handle` with the caller's client and project, keeping its project check and its lineage on the task receipt, and then enter the pack's existing managed staging. No resolver is written in the Comfy hook. An asset map of local files stays valid.
2. *Identity.* The public request keeps the caller's source identity and range exactly as written, so its digest and provenance do not change. Preparation records two distinct things: the source (digest, range in source seconds, fit) and the prepared source (digest, frame count, the cut, rate and size mapping applied). `compile_stages` stops overwriting preparation's asset records (`shared/stages.py:119`).
3. *One coordinate view.* After prepare, every stage works in prepared-clip coordinates: time zero is the range start and the canvas is 1024×576. Compile binds the prepared file at offset zero. Compose and verify take their offset from the prepared-source record, not from the request's range as they do today (`shared/compose.py:336-352`; `shared/verify.py:72-88`). Protected pixels and sound are compared with the prepared baseline; provenance names the original.
4. *Conformance, bounded.* The range must lie inside the media, or the request is refused with both values. The prepared clip has `round((end − start) × 24)` frames, timestamps rebased to zero at a constant 24 per second; a continuation needs at least 39. Frame rate is changed by resampling the picture, never by changing speed or pitch. Size is changed by filling or fitting 1024×576 with the shape kept. Over the selected interval, surplus sound is trimmed to the picture; a shortfall or offset of at most one frame (1/24 s) is padded with silence and recorded; anything larger is refused as missing sound, naming the interval. Media that cannot be read or probed is refused; today a file that returns no stream list passes (`shared/prepare.py:213-217`). The existing strict check then runs on the prepared file, so the graph still receives only exact input.
5. *Masks and regions.* A supplied mask or pixel region must already match the prepared canvas and the clip-relative clock. A mismatch is refused, naming what was expected and what was given. Nothing is reprojected in this plan.

**Contract card (re-check against the code at dispatch; Plan 59's H3 pilot track may already have changed part of this).** In `tests/packs/h3_av/test_source_rate_prepare.py`: `::test_23976_source_is_rejected_on_every_source_backed_route`, `::test_wrong_size_source_is_rejected_with_conform_command` and `::test_vfr_source_is_rejected` change from "refused" to "conformed, recorded, and the prepared file passes the strict check". `::test_audio_duration_mismatch_still_fails_preflight` stays a refusal: its 0.3 s of missing sound is beyond the one-frame bound. Removed: `SOURCE_AV_CONFORM_COMMAND` and its hint (`shared/prepare.py:159-160`). The "must start at zero" refusal (`shared/timing.py:153-154`) no longer reaches the caller, because prepare hands the graph a clip that starts at zero. Assertions in `test_managed_asset_staging.py`, `test_real_media_preflight.py`, `test_source_frame_fit.py` and `test_mask_contract.py` that pin staged identities, source offsets or mask sizes are listed with their old and new meaning before any is touched. **Proof (CPU, real media, the smallest form of each).**

1. *Handles end to end.* A digest handle and a handle to an earlier run's output are each followed from admission, to the bytes the compiled graph is bound to, to the saved build state, to compose and verify, with no asset map written by hand. A handle from another project and an unknown handle are each refused before any pod, with the handle named.
2. *A middle range.* From a file with a visible frame counter and a click track, a range in the middle prepares to exactly the expected source frames, with the click within one frame of where it was.
3. *Edges.* A range that needs rounding; a range outside the media, refused; the existing short-sound file, still refused; a source with no sound where the route requires it, refused; an unreadable file, refused.
4. *A masked edit on footage that is not 16:9,* once under Fill and once under Fit, carried through compose and verify with protected pixels and sound compared against the prepared baseline; a mask sized for the original footage is refused.
5. *The pilot.* The pinned Morpheus request (as in RH-2) returns ready from `astrid generate video --entry h3 --mode v2v --placement runpod --dry-run`, with no file made by hand and nothing rented; its prepared clip probes as 24/1 constant, 1024×576, 78 frames, cropped and not stretched.
