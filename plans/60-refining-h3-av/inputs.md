Tool work is pulled by the skills: each tool step in [tasks](tasks.md) names the task skill that needs it, and a fix nothing needs is dropped or filed. Extend the existing pack; no new pack and no new command. Three kinds of answer, chosen per need: a line in a skill where the need is a choice; the smallest code where it is mechanics; deletion where it is neither. Considered and not chosen: a wrapper command that turns "this clip, this line" into a request; reviving LanPaint as the route for sound inside footage (the pinned nodes already do the masking; LanPaint stays only as the reference for edge handling until the GPU result); rewriting everything onto request version 2.

## Owner decisions

- **D1 — LanPaint.** Decided 16 November 2026. The owner wants sound regenerated inside existing footage ("I think we need that functionality ultimately") and asked whether the node packs already allow it. The pinned primitives support it: they mask picture and sound separately, so the route is the pack's own masked edit with a sound mask that Astrid builds, composes and qualifies (RH-6), with no LanPaint and no upstream change. The unreachable LanPaint helper and graph are removed once RH-5's takes show the native route is usable, not before: it costs nothing to keep for a few days, it is the only worked example of blending the edges of a regenerated span, and if RH-5 shows the edges are the problem, the next question is whether to adopt LanPaint's sampler as a pinned dependency, which is then decided on evidence.
- **D2 — One request shape, and the working version 2 branches.** Decided 16 November 2026 ("I go with all of your recommendations"): version 1 is the one documented shape for continue, change a region and generate; the character swap stays as a separately documented experimental version 2 request; the other working version 2 branches are retired in RH-3, after RH-1 gives version 1 a source range anywhere in the file. A version 2 request without the character swap is then refused with its replacement named: version 2 image-reference generation becomes `operation: generate` with `references`; version 2 continuation becomes `operation: continue`; version 2 masked edit becomes `operation: edit` with a mask. It is an intended change to an experimental interface; no search can show that nobody outside sends version 2 requests.
- **D3 — The `astrid h3` command.** Decided 16 November 2026: it goes ("It should just be part of the generate thing"). `astrid generate video --entry h3` is the one way in; a short migration note says `--dry-run` replaces `plan` and a request file replaces `edit`.
- **D4 — Footage and canvas of any size.** Decided 16 November 2026: Fill by default, never a stretch, and H3 through generate "should work on flexible crop sizes. So any dimensions". As built in RH-1: any input size and shape is accepted and conformed; the output canvas follows the request (the source's own shape, or a stated shape or size), resolved by one stated rule to the nearest size on multiples of 32 within the pack's pixel budget and reported in the dry run; 24 frames a second and the model's frame grid stay fixed because the model's nodes fix them. Quality on shapes other than 16:9 is unknown until a GPU run.
- **D5 — Transcription and masks.** Decided 16 November 2026 for transcription: "just a skill reference here ... or it could even be a workflow that this includes". It is a reference page in RH-2 plus one included text-transcription workflow if the pinned Whisper node runs on the worker; not a separate plan and not a dependency. Word times remain in Plan 59's log. Masks from a description stay with Plan 59 until task skill RH-7 needs one.
- **D6 — Release and review.** Decided 16 November 2026: this plan is in Release 14 beside Plan 59, on `release/14/plan-60` branches, with one review stop after RH-1 and one review round at the end. Adding it to the release's Included plans list is the release manager's step.
- **D7 — How a take is put on the timeline for review.** Decided 16 November 2026: a stored alternate. The take is added as its own clip above the shot with the existing add and trim commands, showing only its generated part at normal speed with the shot's temporary voiceover silent over exactly that span, the original untouched beneath, at a pinned revision. The method is rehearsed at no GPU cost before the first paid trial (RH-2). A detached review draft using `--swap-asset`, which changes only the local copy until it is committed, is the fallback for a take if a stored command cannot do one of those steps, and is stated as such.
- **D8 — Money.** Decided 16 November 2026, with these rules from the second critique. $25 is the hard total for everything: this plan's trials, the pilot already funded under Plan 59 ($3), and Plan 59's own fresh-agent trial on a different timeline (C8).
