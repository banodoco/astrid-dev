# Tasks — Extensible timeline editing

[Plan](plan.md) · [Inputs](inputs.md)

A draft can use a short outline with unknowns. Before dispatch, every task needs one bounded outcome, its input and deliverable, dependencies, a suitable route, and focused proof. Name source identity where one task consumes another project's output. Reuse the prior-art and source identities in [inputs.md](inputs.md); don't repeat them.

**Task ids:** `TL-<n>` for the command layer, `EX-<n>` for the extension proof (`EX-P` is the pack-op proof in phase A; `EX-2` to `EX-4` are the optional phase C view); the `CC-<n>` ids (the commit contract, formerly phase 0; CC-8 was cut) are [Plan 63's](../63-dependable-saving/tasks.md). **Phases:** **A, agents and packs (about 18 days; Agent and Runtime only, no App code): TL-1, RS1, TL-2, TL-3r, TL-3e, TL-13a, TL-13b, EX-P**, after Plan 63's server track; **B, editor gestures as commands (about 44 days): the rest of the table**, after Plan 63's R0 and the owner's week; **C, the alternate view (about 8.5 days): optional and deferred.** **Critical path:** phase A: TL-1 (4 d), RS1 (1), TL-3r (1.5), TL-3e (1.5), TL-13a (3.5), EX-P (2.5); phase B: TL-4, TL-5, TL-10, TL-12, R (see [below](#critical-path-and-estimates)). **Test inventory:** the existing test files this plan affects are listed [below](#test-inventory).

Paths: App paths are under `src/tools/video-editor/` unless they begin `scripts/`, `src/integrations/` or `config/`. "Agent" is astrid-agent, "Runtime" is astrid-runtime. Line numbers cite the template branch (`task/plan59-shot-trim`) and **will have moved after Release 14: re-check against the code at dispatch**.
