## Decision

The ten strict xfails correctly record an intentional retirement of the legacy direct writer. That finding does **not** establish that the current commit-path replacement is correct. A later exact-pair Nightly run observed six failures among the 17 modern clip-replacement integration cases (11 passed), so replacement correctness remains unestablished and the six outcomes require the manager's separate X diagnosis. Do not clear the xfail group or treat the existing modern tests as passing qualification based on source inspection alone.

No inaccessible history or private artifact blocks this assessment. The source history, current Runtime tests, pinned Agent command code, retained prior [clip selector log](re1a-re4ab-tooling/clip.log), and the new exact-pair comparison/outcome files are available. The old and modern fixtures require `ffmpeg`/`ffprobe`; that is an execution prerequisite, not missing evidence.

## Supported API and fixture shape

At the measured Runtime head, the public route is `POST /v1/projects/{project_id}/timelines/{timeline_id}/commit`; the handler validates project/timeline scope, requires a commit idempotency key, authorizes the commit provider, and calls `commit_timeline` ([server route](https://github.com/banodoco/astrid-runtime/blob/2777051c06c3d15e14d3e8d13de26b19f875c4bc/runtime_protocol/server.py#L402-L442), [route dispatch](https://github.com/banodoco/astrid-runtime/blob/2777051c06c3d15e14d3e8d13de26b19f875c4bc/runtime_protocol/server.py#L848-L850)). The pinned Agent provides `capture_occurrence_swap_media` (`occurrence.swap-media`) and `capture_parent_swap_media` (`clip.swap-media`) ([Agent R12 command helpers](https://github.com/banodoco/astrid-agent/blob/0e1543e0da2215db9cb3320cfd1083174c3c62a9/astrid/sdk/timeline/native_occurrence_media_commands.py#L233-L310)). Commands bind the selected old/new media, validate project selections and verified media, and are accepted as a canonical commit/revision/receipt/event.

The modern test fixture uses a project-owned occurrence, child clip, media import, selected media pins and verified-media descriptors before commit ([fixture and command setup](https://github.com/banodoco/astrid-runtime/blob/2777051c06c3d15e14d3e8d13de26b19f875c4bc/tests/test_timeline_clip_replacement.py#L91-L275)). Its result helper requires the internal payload to equal the old payload with only the target asset and its new registry binding changed; when applicable it also checks parent and shot payloads stayed unchanged and requires a `timeline.commit` receipt plus one accepted event ([result invariants](https://github.com/banodoco/astrid-runtime/blob/2777051c06c3d15e14d3e8d13de26b19f875c4bc/tests/test_timeline_clip_replacement.py#L292-L324)). This is the right fixture shape for public replacement assertions. A flat legacy parent clip cannot simply be reused as a public command fixture: a retained compatibility test explicitly verifies that the older published `public013` schema rejects `ownership: parent` ([parent schema boundary](https://github.com/banodoco/astrid-runtime/blob/2777051c06c3d15e14d3e8d13de26b19f875c4bc/tests/test_timeline_clip_replacement.py#L403-L421)). Use an occurrence-owned child for the public journey; test parent swap only where the current public command schema permits it.

## Plan 38 / Plan 55 ownership boundary

None of these ten old assertions tests process birth identity, native token rotation, host-spawn custody, or shared-source-closure ownership from Plan 38. They test timeline editing, media selection/integrity, commit idempotency, and route behavior. They also do not exercise Plan 55's warm local job execution, resident sessions, transport, settlement, or invocation contracts. The native commit terminology “publication” here means a timeline revision/commit receipt, not Plan 55 task settlement. Preserve the independently held Plan 38 native-token and installed-pair tests and any Plan 55-owned test rows; do not infer their clearance from this mapping.
