## Platform eligibility and ownership

The previous guards ask whether `os.fork` exists. The existing `posix_native` lane asks `os.name == "posix"`. On the supported Linux/macOS CPython platforms, fork exists and both predicates admit the tests; on native Windows, fork is absent and both exclude them. These predicates are not universally equivalent for hypothetical restricted POSIX Python ports without fork. No such platform is added to the supported scope by this review. The migration is supported-platform-equivalent, not a claim that every POSIX interpreter implements fork.

`posix_native` is a registered platform lane with `default_off=False` and Ubuntu unit-job ownership (`tests/lanes.py:132`). Default pytest selection does not exclude it.
