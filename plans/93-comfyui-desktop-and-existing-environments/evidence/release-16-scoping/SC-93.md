Review this exception explicitly; it can say reachable ComfyUI, installation unknown, and require user confirmation. Define target-only readiness separately from workflow-specific readiness: without an entry or actual compute evidence it reports partial/unchecked, not full ready and not a spurious install recommendation. Keep legacy status enum where possible using typed blocking observation for not-yet-verified (avoid silently changing client interpretation). A warning cannot turn an unchecked prerequisite green. Do not force every list/catalog request to run a GPU job; use bounded read-only probe plus exact-identity compute receipt with freshness/recheck rules, or say unchecked and offer an authorized verification step.
