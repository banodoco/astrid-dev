**Owner and call flow.** Each `workflow_bundle.emit_bundle` (`:3272`) and `emit_bundle_with_candidate` (`:3993`) creates its own ordinary local `BundleReadSet` directly in its frame. It contains a map keyed by configured root and safe relative file identity, with resolved root identity, first authenticated bytes/digest/type/existence, parsed index/pack or live source mapping, and admission/bypass decision. Each invocation owns a different instance; no decorator, ContextVar, thread local, global registry, revocation, hidden state or copied-context inheritance carries it.

Pass it as an explicit private optional argument through `_canonicalize_for_v2_pair`, `_build_v2_sidecar`, `_make_bundle`, `emit_scratchpad_python`/`emit_ready_template_python`, canonical emitter, `_prepare_workflow_for_emit`, `_emit_build_function`, subgraph and node/default/output helpers. Identity-specific scans (`consume.py:564-592,765-895`) and supplemental/staged readers must take the same explicit capability or bypass the memo. Existing external callers keep their current defaults. Use static call-site inventory and dynamic tracing: this is multiple helper signatures, not a single local edit.

**Read set, guards and final refusal.** Admit lazily only when base would first access a path. Check each path component without following links before resolving/reading it; symlinks, outside-root paths, generation directories and any unverifiable path bypass memo and use base's guards and actionable errors in base order. In particular, do not resolve an unused configured root for an empty workflow; generation parent/leaf self-links go to base guards, never speculative observer resolution. Race-prone traversal must fail closed or bypass: an `lstat` alone is not proof of atomic safety, and no observer `RuntimeError` may replace a base refusal.

For eligible reads record every used index, pack, root, marker and transitive evidence needed by a memoized answer, including warmed and supplemental/identity dependencies actually consulted. Each index is witnessed once on first use plus the one final full re-witness; lookup repeats use the authenticated invocation value. An outside-reader dependency that feeds an answer is routed into this explicit reader or that answer bypasses memo. Unsafe bypass decisions are recorded for audit without inventing unused reads. After the last answer-feeding read, including any staged reload, and before any final publication, recheck the whole eligible read set once by full content hash and root/type/absence checks. A detected change refuses and cleans staging without publishing either final member; replay base's actionable corruption error where possible. Ensure nothing after the check can add a memo dependency before publication. A valid changed value may make base publish while this design refuses: that is the Lead-approved class (iii) difference. ABA and changes after the last check remain limits.
