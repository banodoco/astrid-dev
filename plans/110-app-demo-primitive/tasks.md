### Load-bearing scope notes

**APD-1.** Add `applyPatch(id, patch)`, `play()` and `pause()` to the existing `DemoController`; do not rename or replace its other methods. `applyPatch` validates with the public patch contract, applies through `ops.apply`, records the id, is a no-op for a repeat of the same patch and throws on a conflicting or invalid one. `readTimelineArchive` is the existing read-and-verify half of `importTimelineArchive` with no Runtime client; the import flow calls it and is otherwise unchanged. `host.test.tsx` covers valid, repeated, conflicting and invalid patches, play and pause state, no `fetch` to `/api/` or `/v1/` during mount, edits and archive reads, and dispose leaving no portal. Chat needs no App change.

**APD-2.** Gate (about half a day, before other work): with the Passing Shapes and Lantern Valley fixtures, show that the Remotion player, the Three.js sandbox iframe and the chat pane step correctly under a paused Playwright clock. If the player does not, keep seek-per-frame playback, record which feel goals that loses, and continue. Then remove `reducedMotion: 'reduce'`; install and pause the page clock; per frame advance it by one frame, pin every `document.getAnimations()` entry (including same-origin frames) to that time, wait for readiness, and capture. Readiness waits for every visible clip's `data-preview-presented-frame` to equal the timeline frame, not one source URL. Pixel density comes from the spec (default 2). `clock.test.mjs` covers the pinning helper on a static page with a CSS transition, keyframes and a `requestAnimationFrame` loop. Add `compare-frames.mjs` beside the launcher.

**APD-3.** Mechanical: extensions only, no behaviour change. Regenerate source-closure digests with the existing tool and include the before/after list in the PR. Confirm the native build path still resolves explicit `.ts` imports; if it does not, stop and report before changing any element.

**APD-4.** The spec takes Living Composition's grammar: `poses` (`at` in seconds, `name`, `layout`, `panel`, `lanes`), `transition.duration` and `accents` (`at`, `target` anchor, `effect`, `duration`; the spotlight is the first effect). An adapter compiles existing `views`/`beats` definitions unchanged. `conversation.ts` builds on `activityFrame`: messages with `at`, typed prompts and streamed replies paced by a seeded rhythm (bursts, punctuation pauses, chunked streaming), actions with `start`, `end` and `done | failed | waiting`, and returns `ConversationItem[]` for `ConversationPresentation`, pairing calls and results by id. Agent at Work gains a `pacing` setting that is off by default (D5). `timeline/model.ts` accepts an ordered, non-overlapping list of revisions; Timeline Assembly's existing single `revision` still compiles. Timeline edits in the spec sample the same model, and `entry.tsx` applies each frame's interpolated state through `applyPatch` with deterministic ids. All sampling is a pure function of spec and frame. Tests: deterministic typing and streaming, out-of-order overlap, failure status, each edit applied once per state, repeated sampling identical, every rejection (unknown keys, references or anchors, an action ending before it starts, edits overlapping on one clip, events past the end).

**APD-5.** Output size, frame rate and density come from the spec. Titles are off unless a pose sets `title`, and then use `shared/style.ts` fonts and palette. Write a storyboard contact sheet and `inspect`-style timing summary as Living Composition does. One shared `encode` helper and one receipt writer serve this launcher and `render_project.py`; other renderers may adopt them later. Engine `app-demo` (row fields `demo`, `fixtures`; `ASTRID_APP_CHECKOUT` in the environment) reuses an output whose receipt matches the spec SHA-256, App commit and pack commit. `--timeline` reads the archive in the browser with APD-1's reader, so transcripts and multi-clip timelines load; the host's catalogue decides what can be shown, and anything else fails before capture. Manifest check: `preview/examples/app-demo-project/` with an `app-demo` row and an `agent-at-work` row renders; editing only the latter reuses the capture.

**APD-6.** Copy Passing Shapes and record the source commit. Marketing keeps Lantern Valley; re-render it through its wrapper pointed at the candidate pack as a consumer check, without changing marketing.

No titles. If the author needs code or a launcher change, stop and report it as an APD-4 or APD-5 defect.
