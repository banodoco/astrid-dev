# Release 16 — briefs

Every message the Release 16 run sends, prepared in advance. A sender copies the file's text block and replaces each `{NAME}` with its value; nothing else changes. The rules behind them are in [run.md, Delivery](../run.md#delivery-lead-and-managers).

| File | Who sends it | To |
|---|---|---|
| [lead.md](lead.md) | the owner, once | the Lead's Codex session |
| [manager.md](manager.md) | the Lead | each plan's new manager session in Codex |
| [packet.md](packet.md) | a manager | each new ChatGPT chat on the web |
| [luna.md](luna.md) | the Lead, every hour | one Luna helper per active plan |
| [sol.md](sol.md) | the Lead | one Sol helper, once per packet |
| [board.md](board.md) | the Lead, at start-up | the first comment of each new board |
| [messages.md](messages.md) | anyone | nudge, resume and replace |
