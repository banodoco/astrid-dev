# Fixed messages

Fill the `{NAME}`s. Never write a different message.

- **Nudge** (a Luna to a manager, the Lead to a manager):
  `r16-lead: Check-in missed. Run your loop now and post STATUS.`
- **Resume** (a manager to a silent packet chat):
  `Resume {PACKET}. Your branch is p{PLAN}/{PACKET} at {HEAD}. Read the board {BOARD} for messages to you, continue, and end with READY.`
- **Rework** (a manager passes the Luna's REWORK line to that packet's chat):
  `{THE REWORK LINE}. Fix only that, inside May touch, merge release/16/plan-{PLAN}'s head in, run the Proof again, push, and post READY.`
- **Replace** (added at the end of a role's brief, for a fresh session or chat):
  `You replace {OLD NAME}. The state is on {BOARD}, from comment {CURSOR}. Don't redo work that is Done.`
