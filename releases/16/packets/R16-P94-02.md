## What to do

1. In `gpu_environment.py` add `COMPUTE_SCHEMA = "astrid.compute-probe.v1"` and `COMPUTE_PROBE_SOURCE`, a string of Python source run as `python -I -c <source>`. It must print exactly one JSON line and exit 0 whenever it can report: `{"schema", "ok", "torch", "cuda", "devices": [{"name", "capability": [major, minor]}], "arch_list": [...], "operations": {name: bool}, "error": null | {"stage", "type", "message"}}`. It imports torch inside `try` (a failure sets `error.stage = "import"`), records `torch.__version__` and `torch.version.cuda`, checks `torch.cuda.is_available()`, lists devices with `get_device_name` and `get_device_capability`, records `torch.cuda.get_arch_list()`, then runs these operations on device 0 and compares each with the CPU result using `torch.allclose` (loose tolerance for half precision): `matmul_fp32`, `matmul_fp16`, `matmul_bf16`, `conv2d_fp16`, `softmax_fp32`, calling `torch.cuda.synchronize()` after each. The first exception stops the run and is recorded as `error` with `stage` set to the operation name. `ok` is true only when every operation ran and matched. Truncate error messages to 300 characters.
2. Add `classify_compute(raw, *, returncode=0, stderr="", timed_out=False)` returning `{"schema", "ok", "cause", "message", "works", "torch", "cuda", "devices": [names], "operations"}`. `cause` is `None` when ok, otherwise exactly one of: `timed_out`; `probe_failed` (nothing parseable on stdout, or a non-zero exit); `no_torch` (`error.stage == "import"`); `cpu_only_wheel` (torch imported, `cuda` is null); `no_device` (CUDA wheel but `is_available()` false or no devices); `wheel_arch_mismatch` (a device's `sm_<major><minor>` is not in `arch_list`, or the error message contains `no kernel image`); `driver_too_old` (error message contains `driver` and `too old`); `out_of_memory` (message contains `out of memory`); `operation_failed` (any other error; the message names the operation). Check them in that order. `message` is one plain sentence that names the cause and the values involved, for example for `wheel_arch_mismatch`: `This PyTorch (2.5.1+cu124) has no kernels for your GPU (sm_120).`. `works` is one plain sentence saying what would work, for example `Use a PyTorch built for CUDA 12.8 or newer; Astrid's separate ComfyUI install includes one.`; it is an empty string when ok. Never raise on malformed input.
3. Add `probe_compute(python, *, run=subprocess.run, timeout=120.0)`: it runs `[python, "-I", "-c", COMPUTE_PROBE_SOURCE]` with `stdin=subprocess.DEVNULL`, captured text output, `check=False`, the given timeout, and a child environment without `PYTHONPATH`, `PYTHONHOME` and `VIRTUAL_ENV`; it parses the last non-empty stdout line as JSON, and passes everything to `classify_compute`. `OSError` on spawn returns cause `probe_failed` with `message` saying the interpreter could not be started; `subprocess.TimeoutExpired` returns `timed_out`. It never downloads or installs anything and never touches the network.
4. Write `tests/core/generation/test_gpu_compute_probe.py`: (a) `classify_compute` over a table of raw dicts and stderr values, one row per cause plus an ok row, asserting `cause`, that `message` names the numbers, and that `works` is empty only when ok; the RTX 5070 Ti case from the tester run is `devices=[{"name": "NVIDIA GeForce RTX 5070 Ti Laptop GPU", "capability": [12, 0]}]`, `arch_list=["sm_50", "sm_90"]`, torch `2.5.1+cu124` and must read `wheel_arch_mismatch`; (b) `probe_compute` with an injected `run` for success, a timeout, a spawn error and garbage output; (c) one real subprocess run of `probe_compute(sys.executable)` which, with no torch installed, must read `no_torch` (skip it with `pytest.importorskip`-style logic if torch is importable); (d) the script itself: execute `COMPUTE_PROBE_SOURCE` in-process with `exec`, a `unittest.mock.MagicMock` standing in for `torch` in `sys.modules`, and `capsys` for the JSON line, covering a working device, `is_available()` false, `torch.version.cuda = None`, and a matmul that raises `RuntimeError("CUDA error: no kernel image is available for execution on the device")`. The test must never import real torch.
