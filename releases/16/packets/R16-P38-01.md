## What to do

1. Create `runtime_protocol/schemas/host-source-closure-v1.json` with these keys:
   - `schema_version`: 1.
   - `components`: the nine entries now in `verified_host_launch._COMPONENTS` (host, core, sdk, launcher, astrid_entrypoint, astrid_version, astrid_main, astrid_runtime_cli, vendored_workspace_client), same paths.
   - `installed_pair`: `{"components": {"runtime_protocol": "runtime_protocol", "astrid_runtime": "astrid_runtime"}, "rule": "if either path exists (or is a symlink) beside astrid/, both are measured and both must be real directories"}`.
   - `digest_rule`: one sentence: each component's sha256 is the file hash, or for a directory the sha256 of compact sorted-key JSON of the list of `[posix path relative to the directory, file sha256]` pairs sorted by path parts, skipping any path with a `__pycache__` part; the closure digest is the sha256 of compact sorted-key JSON of the component rows `{component, path, sha256}` sorted by component.
   - `vectors`: a list (step 4).
2. In `verified_host_launch.py` add `_closure_definition()`. It reads that file with `json` from `Path(__file__).with_name("schemas") / "host-source-closure-v1.json"`, and caches the result. Do NOT read it at import time: this module is also pinned and run as a standalone stdlib-only launcher. Set `_COMPONENTS = None`. `source_checkout_closure(checkout)` uses `_COMPONENTS` if it is not None (existing test `test_source_checkout_closure_pins_component_sorted_posix_rows` monkeypatches it; in that case do not apply the installed-pair rule so its pinned digest `c076c538...` stays valid), otherwise the file's `components` plus the installed-pair rule. Keep every existing refusal (`HostLaunchError`: missing component, symlink inside a component, `_no_alias`) and the output shape `{"schema_version": 1, "components": [...], "digest": ...}`.
3. Add the installed-pair rule exactly as the Agent does it (`astrid/core/source_identity.py` `source_checkout_closure`): if `runtime_protocol` or `astrid_runtime` exists beside `astrid/`, add both as components; a missing or symlinked one is a refusal.
4. Write the `vectors` list. Each vector is `{"name", "files": {relative path: utf-8 text}, "symlinks": {relative path: target}, "expect": {"components": [...rows...], "digest": "<hex>"}}` or `{"name", "files", "symlinks", "expect_refusal": "missing" | "symlink"}`. Vectors: `source-checkout` (all nine components, plus an ignored `astrid/core/__pycache__/x.pyc` and a nested directory); `installed-pair` (the same plus `runtime_protocol/__init__.py`, `runtime_protocol/schemas/a.json`, `astrid_runtime/__init__.py`); `pair-missing-one` (only `runtime_protocol/` beside `astrid/`: refusal `missing`); `symlinked-component` (`astrid/sdk` is a symlink: refusal `symlink`); `symlink-inside-component` (a symlink file inside `astrid/core`: refusal `symlink`). Compute each expected row and digest with a throwaway script that uses only `hashlib` and `json` and follows `digest_rule` (do not call the function you changed), then paste the results as literals.
5. Write `tests/test_host_source_closure_vectors.py`: for each vector, build the tree under `tmp_path` (write files, then `os.symlink` for symlinks), then assert `verified_host_launch.source_checkout_closure(tree)` matches `expect`, or raises `HostLaunchError` for `expect_refusal`. Also assert: the file's `components` equals the nine entries listed in step 1 (hard-code them in the test); and that `import runtime_protocol.verified_host_launch` in a fresh `python -c` subprocess (cwd = repo root) loads no third-party module and no module from `astrid` or `astrid_runtime`, and from `runtime_protocol` only `runtime_protocol`, `runtime_protocol.errors` and `runtime_protocol.verified_host_launch` (use `sys.stdlib_module_names`).
6. Run `python scripts/artifact_manifest.py` to regenerate `contract/artifacts.json` (it lists `runtime_protocol/schemas/*.json` already).
7. No `pytest.skip`/`skipif`/`xfail`; no network.
