## What to do

1. In `linux_process_binding.py` add `SO_PEERPIDFD = 77` and `class PeerHandle` with `token` (the dict `token(pid)` returns), `authority` (`"pidfd"` or `"peercred"`), `verify()` and `close()` (also a context manager). It owns the pidfd (or None).
2. Add `retain_peer(connection)`:
   - read `SO_PEERCRED` (`struct "3i"`) once: `pid`, `uid`;
   - try `connection.getsockopt(socket.SOL_SOCKET, SO_PEERPIDFD, struct.calcsize("i"))`; unpack the fd. If it raises `OSError` with errno `ENOPROTOOPT`, `EINVAL` or `EOPNOTSUPP`, the authority is `"peercred"` and there is no fd; any other errno raises `LinuxBindingError`;
   - with an fd: read the pid from the `Pid:` line of `/proc/self/fdinfo/<fd>`; if it is `-1` (peer exited) or differs from the `SO_PEERCRED` pid, close the fd and raise `LinuxBindingError("linux peer pidfd names another process")`;
   - capture `token(pid)`; read `SO_PEERCRED` again; if it changed, or the token's `uid` differs from the peer `uid`, close the fd and raise `LinuxBindingError` (keep the existing wording of the two current refusals);
   - return the handle.
3. `PeerHandle.verify()`: re-run the identity match (`_matches(token["words"])`); with a pidfd also `platform.pidfd_send_signal(fd, 0)`; any `ESRCH` or mismatch raises `LinuxBindingError`; on success returns the same token dict. `close()` is idempotent.
4. `peer_token(connection)` becomes: `handle = retain_peer(connection)`, return `handle.token`, close the handle in `finally`. Its return value and keys are unchanged.
5. In `process_binding.py` add `retain_peer(connection)`: Linux calls `linux_process_binding.retain_peer`; every other backend raises `ProcessBindingUnavailable("retained peer authority is not in runtime_protocol for this OS yet")`.
6. Write `tests/test_linux_peer_authority.py` (no `pytest.skip`/`skipif`/`xfail`; use `requires_linux_tree_custody` and `pytest.mark.needs_real_pidfd` from `tests/lanes.py`). Use a small `FakeConnection` class whose `getsockopt(level, option, size)` returns scripted bytes or raises scripted `OSError`s, and a real sleeper child plus `platform.pidfd_open(child.pid)` where a real pidfd is needed:
   - real `socket.socketpair()`: `retain_peer(a).authority` is `"pidfd"` when a direct `getsockopt(SOL_SOCKET, 77, 4)` on the same socket succeeds, else `"peercred"`; `token` equals `token(os.getpid())`; `close()` closes the fd (`os.fstat` on it raises `OSError`).
   - fake peer whose `SO_PEERCRED` names the child and `SO_PEERPIDFD` returns a pidfd of a different process: refused, no fd leaked.
   - fake peer whose `SO_PEERPIDFD` raises `OSError(ENOPROTOOPT)`: authority `"peercred"` and `token["sha256"] == token(child.pid)["sha256"]`.
   - fake peer whose second `SO_PEERCRED` read differs: refused. Fake peer with a uid that differs from the process uid: refused.
   - `handle.verify()` returns the token while the child lives and raises after the child is killed and reaped.
   - `process_binding.retain_peer` raises `ProcessBindingUnavailable` when `_platform` is replaced with `lambda: "win32"` or `"darwin"`.
