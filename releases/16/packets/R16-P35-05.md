Create `scripts/check_user_state_side_stores.py` (standard library only). `PATTERN = re.compile(r"Path\.home\(\)|XDG_(?:STATE|DATA|CONFIG)_HOME|os\.path\.expanduser\(\s*[\"']~")`. `scan_source(text) -> int` counts `PATTERN` matches on every line whose stripped text does not start with `#`. `scan_tree(root: Path) -> dict[str, int]` walks `root/astrid/**/*.py` (sorted, POSIX-style relative paths such as `astrid/skills/state.py`), skips unreadable files, and returns only files with a count above zero.
2. `load_baseline(path)` reads `scripts/reshape/baselines/user_state_side_stores.json`: `{"schema": "astrid.user-state-side-stores.v1", "rule": <text>, "categories": {<name>: <why>}, "files": {<path>: {"count": int, "category": <name>}}}`. `findings(found, baseline) -> list[str]` returns one line for each file that is absent from the baseline (`new side store: <path> uses <n> home/XDG paths; classify it in the baseline with a category and a reason, or use Runtime app-state`) or whose count rose (`<path> rose from <a> to <b>`), and one for a baseline entry whose category is not in `categories`. A count that fell, or a file that no longer matches, is allowed (shrink only). `main(argv)` supports `--check` (exit 1 and print the findings) and `--write` (rewrite only the counts of files already in the baseline, never add a file or a category: adding is a reviewed edit).
