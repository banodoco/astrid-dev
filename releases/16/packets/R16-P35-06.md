## What to do

1. Create `astrid/core/user_choices.py`. Constants: `KEY = "agent.choices"`, `SCHEMA = "astrid.agent-choices.v1"`, `HARNESSES = ("claude", "codex", "hermes")`. Document shape: `{"schema": SCHEMA, "skills": {"disabled_defaults": {"claude": [...], "codex": [...], "hermes": [...]}, "mirror_digest": "sha256:..." | null}}`. The skills file (`skills.json`) keeps `installs`, `setup_selection` and everything else locally: they are machine records (the data-root lookup reads `setup_selection` before any Runtime exists, `astrid/sdk/storage_root.py`). Only `disabled_defaults` moves.
2. `normalize_disabled(value) -> dict[str, list[str]]`: every harness key present, each a sorted list of unique non-empty strings; a non-mapping, an unknown harness, a non-list value or a non-string item is dropped, never raised. `disabled_digest(value) -> str` is `user_state.content_digest(normalize_disabled(value))`. `validate_document(content) -> dict` refuses unknown top-level keys, a wrong schema string, and a `skills` object with other keys than `disabled_defaults` and `mirror_digest`, with a `ValueError` whose message names the key (`user_state.update` lets it propagate).
3. `@dataclass(frozen=True) class Reconciled: value: dict; source: str; wrote_runtime: bool` with `source` one of `file` (no Runtime or nothing to reconcile), `runtime`, `imported`, `file-newer`. `reconcile_skills(*, file_present: bool, file_value, store=None) -> Reconciled` follows these rules in order: (1) no store in scope or the Runtime errors with `unavailable`: return the file value, source `file`. (2) The document is absent: if the file value has any non-empty list, call `user_state_import.run_import` with `import_id="skills-disabled-defaults"`, target `KEY`, `read_source` returning the normalized file value or `None` when every list is empty, and `to_document` building the document with `mirror_digest = disabled_digest(file value)`; return source `imported`; if everything is empty return the file value, source `file`, and write nothing. (3) The document exists and `file_present` is false (a fresh profile or a restored Runtime): return the Runtime value, source `runtime`. (4) The document exists, the file is present and `disabled_digest(file_value) == mirror_digest`: return the Runtime value, source `runtime`. (5) The document exists, the file is present and its digest differs from `mirror_digest`: the file was written while the Runtime was unreachable, or by an older Astrid; the file wins: update the document through `user_state.update` to the file value with the new `mirror_digest`, and return source `file-newer`, `wrote_runtime` true (false if that update fails with `unavailable`).
4. `push_skills(value, *, store=None) -> bool`: update the document through `user_state.update` so `skills.disabled_defaults` is the normalized value and `skills.mirror_digest` is its digest; return true when the Runtime holds it, false when there is no store or it is unavailable (never raise for unavailability). The caller writes the file first and calls this second, so a crash between them leaves the file newer than the Runtime and rule (5) repairs it.
5. Write `tests/test_user_choices.py` with `InMemoryAppState` and `user_state.using(store)`. Cases for each rule: no store; first run imports and the receipt exists; all-empty file imports nothing and writes nothing; fresh profile (document present, file absent) returns the Runtime opt-outs; file equal to the mirror returns the Runtime value even if it differs in order or duplicates (normalization); file edited by hand after sync gives `file-newer` and the document and mirror digest now match the file; `push_skills` then `reconcile_skills` with a file holding the same value returns `runtime`; unavailable Runtime on `push_skills` returns false and on `reconcile_skills` returns the file value; the stored document never contains `installs`, `setup_selection` or any path (assert the document's keys and a `json.dumps` search for `"installs"`); `validate_document` refusals; a list large enough to pass 16 KiB makes `push_skills` return false with no write (the size guard) while the file value stays current.
