## What to do

1. In `runtime_protocol/process_binding.py` keep `LINUX`, `ROTATES_ON_EXEC`, `PRIMITIVE`, `supported()` as they are. Add `class ProcessBindingError(RuntimeError)` and `class ProcessBindingUnavailable(ProcessBindingError)`. Add `def _platform() -> str: return sys.platform` and `def backend() -> str` that returns `"linux"`, `"windows"`, `"darwin"` or `"other"` from `_platform()` read at call time (tests replace `_platform`; never patch `sys.platform`).
2. Add, standard library plus `from . import linux_process_binding, platform` only (never import `service`, `store`, `daemon` or `astrid_runtime`):
   - `identity(pid, *, timeout=1.0)` returns `platform.process_identity(pid, timeout=timeout)`; `birth_matches(expected, actual)` returns `platform.process_birth_matches(expected, actual)`.
   - `token(pid)`: Linux calls `linux_process_binding.token(pid)`; Windows calls `platform.handoff_token(pid)`; Darwin and other raise `ProcessBindingUnavailable("process token provider for this OS is not in runtime_protocol yet")`.
   - `details(words)`: `linux_process_binding.details(words)` / `platform.handoff_token_details(list(words))` / same unavailable error.
   - `peer_token(connection)`: `linux_process_binding.peer_token(connection)` / `platform.handoff_peer_token(connection)` / unavailable.
   - `signal(words, signum)`: first refuse (raise `ProcessBindingError`) any `int(signum)` not in `{platform.TERM, platform.KILL}` plus `platform.USER1` when it is not None; then Linux `linux_process_binding.signal(words, signum)`, Windows `platform.handoff_signal_token(words, signum)`, else unavailable.
   - `resume_once(words)`: raises `ProcessBindingUnavailable("one-shot resume exists only for a suspended Darwin launch")` on every OS for now.
   Call `linux_process_binding.<name>` through the module attribute at call time, so tests that patch it (for example `tests/test_zero_shim_boundary.py`) keep working.
3. In `astrid_runtime/custody_broker.py`, at the top of each of the four functions, add `if process_binding.backend() in ("linux", "windows"): return process_binding.<name>(...)` (for `signal_audit_token` keep the existing `_admitted_signals()` check first) and delete the old `if process_binding.LINUX:` / `if sys.platform == "win32":` branches that this replaces. Leave the Darwin code and the `else` refusal untouched. Lower the bound in `test_real_host_broker_constructs_on_linux_and_custody_branches_stay_in_one_module` to the new `sys.platform` count of that file.
4. Write `tests/test_process_binding_provider.py` (no `pytest.skip`/`skipif`/`xfail`; Linux-only tests carry `requires_linux_tree_custody` from `tests/lanes.py`, pidfd tests also `pytest.mark.needs_real_pidfd`):
   - token of `os.getpid()` round-trips: `details(token["words"])` has the same `pid`, `uid`, `pidversion`, `sha256`.
   - `peer_token(a)` over `socket.socketpair()` has the same `sha256` as `token(os.getpid())`; and with a child holding the other end (`subprocess.Popen(..., pass_fds=[fd])`, child sleeps) `peer_token(parent_end)["sha256"] == token(child.pid)["sha256"]`.
   - `identity(os.getpid()) == platform.process_identity(os.getpid())` and `birth_matches(b, b) is True`.
   - reused or forged token (pidfd tests): a token of a child that has exited and been reaped makes `signal(words, platform.TERM)` raise and signals nothing; a live sleeper child with `words[4] ^= 1` raises and the child is still alive.
   - `signal(words, platform.TERM)` on an owned sleeper child ends it with `-SIGTERM`; `signal(words, signal.SIGHUP)` raises `ProcessBindingError` and the child stays alive.
   - Windows dispatch with fakes: `monkeypatch.setattr(process_binding, "_platform", lambda: "win32")` and fake `platform.handoff_token`, `handoff_token_details`, `handoff_peer_token`, `handoff_signal_token`; assert each provider call reaches the matching fake with the same arguments and returns its value.
   - Darwin: with `_platform` returning `"darwin"`, `token`, `details`, `peer_token`, `signal` raise `ProcessBindingUnavailable`; `resume_once` raises it on every backend.
   - import boundary: a fresh `subprocess.run([sys.executable, "-c", ...], cwd=<repo root>)` imports `runtime_protocol.process_binding` and finds none of `runtime_protocol.service`, `runtime_protocol.store`, `runtime_protocol.daemon`, `astrid_runtime` in `sys.modules`.
