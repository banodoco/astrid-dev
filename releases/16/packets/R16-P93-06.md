## What to do

An **installation observation** is `{"layout": "desktop", "state": <state>, "version": str|None, "endpoint": "http://127.0.0.1:<port>" (where it answers when running, else where it is expected), "recorded": {"executable": str|None, "data_dir": str|None}, "files": {"executable": bool, "data_dir": bool}, "responder": {"kind": "comfyui"|"other"|"denied"|"none", "port": int|None, "base_dir": str|None, "matches_install": bool|None}}`, and `<state>` is one of `running | closed | stale | wrong_responder | denied | ambiguous`.

1. In `local._probe_server` add a keyword `check_shape=False`. After the `/system_stats` answer is parsed, when `check_shape` is true and the answer is not a dict with a dict `system` and a list `devices` (the test at `local.py:282` that Pinokio ports already get through `require_comfyui_shape`), append `{"port": port, "endpoint": "/system_stats", "error": "responder is not ComfyUI"}` to the errors and return `(None, errors)`. Leave `require_comfyui_shape` (the Pinokio path, which stays silent) and all other behaviour as they are. In `scan`, probe the ordinary ports with `check_shape=True`. A non-ComfyUI responder is therefore never in `servers`, and is still reported, as an error entry, as a server answering something other than ComfyUI always was.
2. In `scan`, build `installations` at the end: `from astrid.core.generation import desktop_install` inside the function (avoids an import cycle) and `installations = desktop_install.observe_installations()`. With no Desktop registration (every Linux and macOS machine, and any Windows machine without Desktop) that is `[]` and makes no request. Add `"installations": installations` to the returned dict. Do not add it to the two error returns in `main` for a bad `--ports` value.
3. Update only these two assertions in `tests/packs/test_vibecomfy_local.py` (the whole-response tests at about lines 360 to 374): `test_scan_reports_pinokio_when_no_script_is_running` and `test_scan_continues_when_pinokio_is_absent` now expect `"installations": []` in the full response dict. This is the change R16-P93-02 listed.
4. Write `tests/packs/test_vibecomfy_scan_desktop.py`. Reuse `_server`, `_non_comfy_server` and `_pinokio_server`-style helpers by importing them from `tests.packs.test_vibecomfy_local`. Monkeypatch `desktop_install.read_registrations` to return one registration whose `data_dir` is the temp folder the fake server uses (its `custom_nodes` parent) and whose `executable` is a file you create, and monkeypatch `desktop_install.DESKTOP_CANDIDATE_PORTS` to the fake server's port. Cover: running (state `running`, the server also in `servers`, `errors` empty); closed (nothing listening); stale (executable file missing); a non-ComfyUI JSON server on the candidate port (state `wrong_responder`, the server not in `servers`, `errors` has one `responder is not ComfyUI` entry for that port); a plain non-ComfyUI responder on an ordinary scan port is not in `servers` and appears once in `errors`; a server answering `{"system": {}}` without `devices` is rejected the same way; `installations` is always present and is `[]` with no registration.

## Done when

- A server that is not ComfyUI is never in `servers` on any port, and appears in `errors`.
- `installations` carries each Desktop state, tied to the responder by data folder.
- Every other test in `tests/packs/test_vibecomfy_local.py` passes unchanged.
