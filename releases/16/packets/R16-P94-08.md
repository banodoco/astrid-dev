## What to do

1. `download_archive(pin, archive_path, part_path, progress, *, client=None, deadline=None)`: build `entry = {'name': archive_path.name, 'subdir': '', 'url': release url, 'sha256': archive_sha256, 'size_bytes': archive_bytes}` and call `astrid.core.generation.asset_alignment.fetch_verified(entry, archive_path, root=archive_path.parent, part=part_path, label=archive_name, client=client, deadline=deadline, progress=<wrapper>)`. It resumes the part with a Range request and removes the file and part on a size or SHA-256 mismatch. Read `vibecomfy.fetch._verification_receipt_path` and, as `asset_gaps._fetch_into_folder` does, remove any receipt file or folder the call created under `archive_path.parent` so only the archive remains. Wrap `IntegrityError` as `PortableError('archive_mismatch')` (message names the archive and says it was refused and removed) and any other failure as `PortableError('download_failed')` (message says the partial copy is kept and a rerun resumes). The progress wrapper calls `progress('download', done, release['archive_bytes'])`; the CLI prints `Downloading ComfyUI: <done> of <total>` from it.
2. `extract_archive(archive_path, staging_dir, pin)`: create `staging_dir`. For `archive_format == 'zip'` use `zipfile` and refuse (`PortableError('unsafe_archive')`) any member that is absolute, contains `..`, a backslash traversal or a drive letter, is a symlink (check `external_attr`), or would make the unpacked total exceed `1.1 * extracted_bytes`. For `7z` run `[tar_executable, '-xf', str(archive_path), '-C', str(staging_dir)]` with `subprocess.run(check=True, stdin=DEVNULL, timeout=3600)` where `tar_executable = shutil.which('tar')` (missing -> `PortableError('no_extractor')` naming `tar`), then walk the tree and refuse any symlink or any path that resolves outside `staging_dir`. Write nothing outside `staging_dir`.
3. `missing_files(root, pin)` returns the sorted `required_files` that are not non-empty regular files under `root`. `default_steps(client=None, deadline=None)` returns `Steps(download=..., extract=extract_archive, missing=missing_files)` with `client` and `deadline` bound.
4. Write `tests/core/generation/test_comfy_portable_steps.py`: a real download of a small served zip with `serve_release` and `httpx.Client()` (with a fixture pin whose `archive_bytes` and `archive_sha256` are computed from the bytes): whole download; an interrupted download (`break_after`) leaves `.part` and a rerun resumes with a Range request and ends with the verified archive and no extra files in the archive folder; a served file with the wrong bytes raises `archive_mismatch` and leaves no archive and no part; unpack of a good zip built with `make_zip` (with `ComfyUI_windows_portable/` as the inner folder) yields the required files; zip-slip (`../evil`), absolute, drive-letter and symlink members each raise `unsafe_archive` and write nothing outside the staging folder; a size bomb raises `unsafe_archive`; the 7z path with `subprocess.run` and `shutil.which` monkeypatched asserts the exact argv, that a missing `tar` raises `no_extractor`, and that a symlink planted in staging by the fake run is refused; an end-to-end `install_portable` with `default_steps` against the served zip ends `complete`, and the same run interrupted by `break_after` then rerun resumes and completes. Real 7z unpacking is not tested here (see Later, ER-L0).

## Done when

- The install's download resumes and refuses a bad hash; the unpack refuses escaping members; the end-to-end install against a local server completes and resumes.
- Only the archive folder and the staging folder under `.astrid-install` are written by these steps.
