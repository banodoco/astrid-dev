## What to do

1. In `platform.py`, move the Linux scope building now inline in `process_identity` (boot id from `/proc/sys/kernel/random/boot_id`, pid-namespace inode from `/proc/<pid>/ns/pid`, each optional when unreadable) into `linux_birth_id(pid, start_ticks, *, proc_root=Path("/proc"))`, returning `f"proc-start-ticks:{start_ticks}{scope}"`. `process_identity` calls it. The string it returns must not change by a byte; run `tests/test_native_custody.py` and the provider tests to prove it.
2. In `linux_process_binding.py` add:
   - `birth_ticks(birth_id)`: the integer start ticks of a `proc-start-ticks:` birth id; `None` for any other string, including the old `<boot-uuid>:<ticks>` form (decision D3: old-format journals read as unknown).
   - `zombie_birth(pid, *, proc_root=Path("/proc"))`: `""` unless `<proc_root>/<pid>/stat` shows state `Z`; then `linux_birth_id(pid, ticks, proc_root=...)`. Any `OSError`, `IndexError`, `UnicodeError` or non-digit ticks returns `""`. The result equals what `process_identity` would have returned while the process was live.
   - `census(*, proc_root=Path("/proc"))`: a dict `{"entries": {pid: {"pid", "parent_pid", "pgid", "session", "uid", "birth_id"}}, "exited": {pid: birth_id}, "failure": None | str}`. Port the logic of the Agent's `astrid/core/execution/process_group.py` `_linux_process_snapshot` and `_linux_process_record` (read `stat` and `status` through one `/proc/<pid>` directory descriptor, split `comm` with `rpartition(b")")`, effective uid from the `Uid:` line, state `Z` goes to `exited` only, state `X` is dropped, a vanished pid gives no witness, a child whose parent is missing from the listing is re-read once and dropped if its birth changed), but build each `birth_id` with `platform.linux_birth_id`. On `OSError`/`ValueError`/`UnicodeError` return `{"entries": {}, "exited": {}, "failure": "/proc census unavailable: <error>"}`. It never spawns a process.
3. In `process_binding.py` add `census()`, `zombie_birth(pid)` and `birth_ticks(birth_id)`: Linux delegates; the other backends raise `ProcessBindingUnavailable("this census stays with the caller on this OS")` for `census` and `zombie_birth`, and `birth_ticks` returns `None`.
4. Write `tests/test_linux_census.py` with fake `/proc` trees under `tmp_path` (a `sys/kernel/random/boot_id` file, then `<pid>/stat` and `<pid>/status` files in the same shape as the Agent's `tests/core/execution/test_rn15_proc_census.py` `_row` helper: stat line `"{pid} ({comm}) {state} {ppid} {pgid} {session} ..."` with the start ticks in field 22 and `Uid:` line in `status`) and the real `/proc` for one live-process check. Cover: tricky `comm` values (space, nested parentheses, newline, non-ASCII); zombie goes only to `exited`; `X` dropped; vanished directory gives no witness; reparented child re-read; reused child not spliced onto a fresh parent; births have the form `proc-start-ticks:<n>;boot:<id>` (no `pidns` in fake trees); `census()` of the real `/proc` lists `os.getpid()` with `birth_id == platform.process_identity(os.getpid())["birth_id"]`; `zombie_birth` of a real exited-unreaped child equals the `birth_id` seen while it lived; `birth_ticks` of a real birth id is an int, of `"<uuid>:123"` and `""` is `None`; failure path when `proc_root` has no `sys/kernel/random/boot_id`.
5. No `pytest.skip`/`skipif`/`xfail`; Linux-only tests use `requires_linux_tree_custody` from `tests/lanes.py`.
