## What to do

1. Finding to bake in: the existing placement is two writes. `targets.save_target(TargetRecord(...))` selects the install (`astrid/core/generation/targets.py`), and `settings.set_placement(url, client)` saves the attached endpoint default (`astrid/core/generation/settings.py`; `generate settings set placement`). Astrid does not launch Windows processes (`target_launch.ProcLaunchObserver` reads Linux procfs), so the supported start is the person's: the release's `start_script` in the install root.
2. `attach_installation(result, *, pin=None, port=8188, client=None)` takes the `InstallResult` from `install_portable` (refuse with `PortableError('not_installed')` unless `result['python']` and `<comfy_dir>/main.py` are non-empty files). It reads the previous selection first: `previous_target = targets.read_target()` as a dict or `None`, and `previous_placement = settings.placement_default(client)`.
3. Build `targets.TargetRecord(engine='comfyui', location='local', owner='human', layout='portable', endpoint=f'http://127.0.0.1:{port}', root=str(comfy_dir), python=str(python), facts={'installed_by': 'astrid', 'release': tag, 'start_script': str(root/start_script), 'launch_app': str(comfy_dir/'main.py'), 'launch_argv': [str(python), '-s', str(comfy_dir/'main.py'), *pin['launch_args'], '--port', str(port)]}, verified_at=None)`. Save it with `targets.save_target(record)`, then `settings.set_placement(endpoint, client)`. Calling it twice with the same result changes nothing the second time (same saved record, `previous_target` equal to the record).
4. Return `{target: record.as_dict(), placement, previous_target, previous_placement, undo: 'astrid generate settings unset placement', start: {who: 'person', script, text}}` where `text` is `Start ComfyUI by opening <script>. Then ask me to check again.`. No new setting, store or file is introduced; do not start any process and do not probe the network.
5. Write `tests/core/generation/test_comfy_portable_attach.py`: build a fake finished install in `tmp_path` (the required files, `python_embeded/python.exe` with mode `0o755`) with a fixture pin; assert the saved record via `targets.read_target()`, the placement via `settings.placement_default()` (the conftest provides the in-memory settings store and a sandboxed home), `previous_target` and `previous_placement` for a machine with an earlier saved choice (a `layout='desktop'` record and a different placement) and for a clean machine (`None` and `{}`), idempotence on a second call, `PortableError('not_installed')` and no write when the files are missing, and that `target_launch.prepare_target_launch(record)` accepts the record (it validates the argv, root, Python and port; the test creates the files it needs).
