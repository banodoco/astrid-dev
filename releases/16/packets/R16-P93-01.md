## What to do

Background. Tester report #1848 recorded one real fact about Desktop: version 0.7.2 stayed registered after its executable and data folder were gone, and the scan returned no servers and no errors. It recorded no paths, port or endpoint payloads, so the shapes below are assumed from Desktop's public layout and are labelled so. Use `<user>` and `<gpu>` for anything personal; never a real path.

1. Create the four JSON files. Each has the keys `state`, `source_report` (`"banodoco/astrid-dev#1848"`), `shape_basis` (`"assumed from Desktop's public layout; #1848 records only version 0.7.2 and the missing paths; not yet verified on a real Windows machine"`), `registration`, `files`, `responders`, `tells_apart` (a list of short strings).
   - `registration` is `{"source": "registry+config", "version": "0.7.2", "executable": "C:\\Users\\<user>\\AppData\\Local\\Programs\\ComfyUI\\ComfyUI.exe", "data_dir": "C:\\Users\\<user>\\Documents\\ComfyUI", "server_port": 8000}` in all four.
   - `files` is `{"executable": bool, "data_dir": bool}`; `responders` maps a port string to a responder. A responder is one of: `{"kind": "none"}`; `{"kind": "other", "system_stats": {"status": "ok"}}`; `{"kind": "comfyui", "system_stats": {"system": {"comfyui_version": "0.8.0", "python_version": "3.12.9", "embedded_python": false, "argv": ["main.py", "--base-directory", "C:\\Users\\<user>\\Documents\\ComfyUI", "--port", "8000"]}, "devices": [{"name": "cuda:0 <gpu>", "type": "cuda"}]}, "folder_paths": {"custom_nodes": ["C:\\Users\\<user>\\Documents\\ComfyUI\\custom_nodes"]}}`.
   - `running`: both files true; port `"8000"` is the `comfyui` responder above. `closed`: both files true; port `"8000"` is `none`. `stale` (the #1848 state): both files false; `responders` is `{}`. `wrong_responder`: both files true; port `"8000"` is `other`.
2. In `tests/fixtures/comfyui_desktop/__init__.py` add `FIXTURE_NAMES = ("running", "closed", "stale", "wrong_responder")`, `load(name)` (a fresh deep copy of the JSON), `get_json_for(fixture, *, denied_ports=())` and `facts(fixture)`.
   - `get_json_for` returns `get_json(port: int, path: str)` that raises the same exception types the real probe sees: a port with no responder, or kind `none`, raises `urllib.error.URLError(ConnectionRefusedError(111, "refused"))`; a port in `denied_ports` raises `urllib.error.URLError(PermissionError(1, "Operation not permitted"))`; kind `other` answers `/system_stats` with its payload and raises `urllib.error.HTTPError(url, 404, "Not Found", {}, None)` for any other path; kind `comfyui` answers `/system_stats` and `/internal/folder_paths` with its payloads and 404s any other path.
   - `facts(fixture)` returns `{"files": (exe_exists, data_dir_exists), "port_kind": <kind of the responder on server_port, "none" when absent>, "base_dir_matches": bool | None}`, where `base_dir_matches` compares the parent of `custom_nodes[0]` with `registration["data_dir"]` for a `comfyui` responder and is `None` otherwise.
3. Write the tests: every fixture loads and has all keys; every string value in every fixture is redacted (any Windows path starts with `C:\Users\<user>\`, written JSON-escaped in the file, and no value contains `@`, a drive letter other than `C:`, or an IP other than `127.0.0.1`); the four `facts(...)` results are pairwise different; `stale` has both files false and no responders (the #1848 state); `get_json_for` raises the exact exception types above for none, denied, other and comfyui (check `isinstance(exc.reason, ...)`); `load` returns an independent copy each call.
