## What to do

The module writes nothing, starts nothing, and imports only the standard library at the top (it imports `astrid.packs.vibecomfy.local` lazily, inside the default probe). Windows behaviour is simulated: every path, environment value, registry value and HTTP answer enters through an injectable seam, so the tests run on Linux.

An **installation observation** is `{"layout": "desktop", "state": <state>, "version": str|None, "endpoint": "http://127.0.0.1:<port>" (where it answers when running, else where it is expected), "recorded": {"executable": str|None, "data_dir": str|None}, "files": {"executable": bool, "data_dir": bool}, "responder": {"kind": "comfyui"|"other"|"denied"|"none", "port": int|None, "base_dir": str|None, "matches_install": bool|None}}`, and `<state>` is one of `running | closed | stale | wrong_responder | denied | ambiguous`.

1. `read_registrations(environ=None, *, registry=None, read_text=None) -> list[dict]`. Sources: (a) the registry entry, from `registry()` (default `_windows_registry`, which returns `None` unless `sys.platform == "win32"` and otherwise reads the HKCU Uninstall entry whose `DisplayName` is `ComfyUI` with `winreg`, returning `{"DisplayVersion", "InstallLocation", "DisplayIcon"}`); (b) the file `<APPDATA>\ComfyUI\config.json` from `environ`, read with `read_text(path)` (default: UTF-8 `Path.read_text`, any error means absent), whose string `basePath` is the data folder. Join with `ntpath` when `APPDATA` contains a backslash, else `posixpath`. Return `[]` when neither source exists, else one registration `{"source": "registry" | "config" | "registry+config", "version": DisplayVersion or None, "executable": <DisplayIcon with quotes and a trailing ",0" removed, else InstallLocation + "\\ComfyUI.exe", else <LOCALAPPDATA>\Programs\ComfyUI\ComfyUI.exe when LOCALAPPDATA is set, else None>, "data_dir": basePath or None, "server_port": 8000}`. This is the same shape as the fixtures' `registration`. The real registry read cannot be tested in a chat; keep it small and mark it `# pragma: no cover`.
2. `path_equal(a, b)` and `parent_dir(path)`: if either value has a backslash or a drive letter, compare with `ntpath` (`normpath` after turning `/` into `\`, then `normcase`); otherwise `posixpath`. `parent_dir` uses the matching `dirname`.
3. `DESKTOP_CANDIDATE_PORTS = (8000, 8188)` (read at call time, so tests can monkeypatch it). `probe_ports(ports, *, get_json=None) -> dict[int, responder]` where `get_json(port, path)` defaults to `astrid.packs.vibecomfy.local._get_json(f"http://127.0.0.1:{port}{path}", timeout=1.0)`. For each port: `GET /system_stats`; a `PermissionError` anywhere in the exception chain (the exception, its `.reason`, its `__cause__`) gives `{"kind": "denied"}`; an HTTP error (an integer `.code`) or a `ValueError` gives `{"kind": "other"}`; any other failure (refused, timed out) gives `{"kind": "none"}`. A dict with a dict `system` and a list `devices` is `comfyui`: then `GET /internal/folder_paths` and take `parent_dir` of the first string in `custom_nodes` as `base_dir` (any failure leaves `base_dir` as `None`); `version` is `system.comfyui_version` when a string. A dict of any other shape is `other`. Each responder is `{"kind", "base_dir", "version"}`.
4. `classify(registration, *, files, responders) -> installation observation`, pure. Rules in this order: (a) any of `files` false means `stale` (endpoint is the expected one, responder `None`; a responder is never consulted); (b) the responders are tried with the expected port (`registration["server_port"]`) first: a `comfyui` responder whose `base_dir` `path_equal` the registration's `data_dir` means `running` at that port (`matches_install` true); (c) otherwise, at the expected port: `denied` means `denied`; `other` means `wrong_responder`; `comfyui` with a different `base_dir` means `wrong_responder` (`matches_install` false); `comfyui` with `base_dir` `None` means `ambiguous` (`matches_install` `None`); (d) otherwise, a `denied` on any other candidate port means `denied`; (e) otherwise `closed`. A different ComfyUI on another port while Desktop is closed does not change `closed`. `endpoint` is the running port's URL, else `http://127.0.0.1:<server_port>`.
5. `observe_installations(*, environ=None, registrations=None, get_json=None, exists=None, read_text=None, registry=None) -> list[installation observation]`: registrations from `read_registrations` unless given; `exists(path)` defaults to `os.path.exists`; `files` from `exists` on the recorded paths (a `None` path counts as missing); probe the candidate ports only when no file is missing; `classify` each. With no registration it returns `[]` and makes no request.
6. `select_candidate(installations, servers) -> {"outcome": "none"|"one"|"several", "choices": [...], "not_running": [...]}`: `choices` has one entry per `running` installation (`{"layout": "desktop", "endpoint", "label": "ComfyUI Desktop"}`) and one per scan server (`servers` is the `servers` list from `astrid.packs.vibecomfy.local.scan`) whose `url` is not already a choice (`{"layout": "other", "endpoint": url, "label": "ComfyUI at <url>"}`, with `" (Pinokio)"` appended when the server has `pinokio_apps`); `not_running` is every installation that is not `running`.
7. Write `tests/core/generation/test_desktop_install.py`, importing the fixtures from `tests.fixtures.comfyui_desktop`. Cover: `read_registrations` with a fake `registry` and `read_text`, with only the config, only the registry, neither (`[]`), invalid JSON, and a registry `DisplayIcon` like `"C:\\...\\ComfyUI.exe",0`; `path_equal` across case, slash direction and trailing slash on Windows paths, and on POSIX paths; for each fixture, `classify` after `probe_ports(get_json=get_json_for(fixture))` gives its `state` (`running`, `closed`, `stale`, `wrong_responder`) with the expected `endpoint`; `denied` from `get_json_for(fixture, denied_ports=(8000,))`; `ambiguous` when `/internal/folder_paths` 404s on an otherwise good responder; a ComfyUI whose `custom_nodes` parent is another folder on port 8000 is `wrong_responder` with `matches_install` false; Desktop moved to port 8188 (running responder only there) is `running` at 8188; Desktop closed while a different ComfyUI answers on 8188 is still `closed`; a stale registration never calls `get_json` (a fake that fails the test); `observe_installations` with no registration makes no call; `select_candidate` for none, one Desktop, Desktop plus a Portable server (`several`), and a server whose URL equals Desktop's endpoint (one choice, not two). The default probe: monkeypatch `astrid.packs.vibecomfy.local._get_json` and check `probe_ports` URLs and the one-second timeout.

## Done when

- Each fixture state classifies to its own state with the facts that tell it apart; a wrong responder on Desktop's port is never `running`.
- A stale registration is reported without any request, and nothing is written or started.
- `denied` and `ambiguous` are reported, not guessed around.
