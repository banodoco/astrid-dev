5. In the same file: `make_zip(entries: dict[str, bytes]) -> bytes` (standard `zipfile`, deflate) and `serve_release(files: dict[str, bytes], *, break_after: int | None = None)` as a context manager that starts a `http.server.ThreadingHTTPServer` on `127.0.0.1` port 0 in a thread, serves `files` by URL path (`/<name>`), honours `Range: bytes=N-` with `206` and a correct `Content-Range`, records requests as `server.requests` (list of `(path, range_header)`), and yields the base URL (`http://127.0.0.1:<port>`) with the server object available as `server`.
