# Release 15 — Stability

**Release:** 15
**State:** Draft

## Highlight

Every test passes on every platform and stays passing, and the generation failures users can hit are fixed.

## Intent

Release 13 lost hours telling new failures from old ones, and some red tests hide real bugs. This release makes green mean working. A good outcome: three consecutive green nights on Agent, Runtime and App, required checks on every pull request, and the reliability items deferred from Release 13 closed or deliberately dropped.

Proposed by the advisor and agreed by Hannah on 15 November 2026 (version 0.1 is "focused on hardening, updates, stability and speed"), with fixes and plans added on the fly from actual usage and user reports. See [Strategy](../strategy.md#decisions).

## Approach

After the speed release, because that release rewrites the path every job takes and about ten deferred items change or disappear with it. Start by re-measuring on the published Release 14 code; fix by cause, never by loosening a test; classify each red test as a stale test or a real bug first. Includes the money-safety items for rented machines, because they can cost a user money: a rented machine that cannot stop itself when the person's computer sleeps, and a failed clean-up that leaves one billing. Offline tests of the rented-machine boundaries so those failures are found without renting.

The Windows tester run of 15 November 2026 found six generation failures in one afternoon that no automated test had ever executed, because Windows checks covered installing and starting only. So this release also adds: a generation against a real ComfyUI on CPU in CI on Linux, macOS and Windows ([#678](https://github.com/banodoco/astrid-dev/issues/678)); a Windows update from the previous release ([#679](https://github.com/banodoco/astrid-dev/issues/679)); the unit tests run on Windows itself, not on Linux with the platform name faked ([#680](https://github.com/banodoco/astrid-dev/issues/680)); a first run on macOS with a person's own ComfyUI ([#681](https://github.com/banodoco/astrid-dev/issues/681)); a check of whether the network guard is enforced on Windows ([#682](https://github.com/banodoco/astrid-dev/issues/682)); and errors that name the real cause ([#683](https://github.com/banodoco/astrid-dev/issues/683)).

Each release has one theme and a [standing lane](../skills/astrid-dev-shared/glossary.md).
