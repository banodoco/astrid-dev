## Contract

- A helper (beside `install_identity`) returns the **install stamp**: a digest over the version identity and the staged manifest's content digests for the shipped tree (a full content-digest manifest of the installed shipped pack and model-catalog files written at install time; verifying a single file against it must be possible). It returns `None`, with a named reason, for anything that is not a managed install (an editable checkout, a development tree, a tree with a write bit on a shipped file, a missing or mismatched manifest). Nothing may treat `None` as a stamp.
- The installer writes the shipped tree (Python, pack and catalog files, the model catalog `models.yaml`, pack manifests) with write bits removed, directories included, and the **update and uninstall paths still work** (they restore the write bit through the existing cleanup, `_pack_cleanup.py`). A rollback to an older Runtime still works.
- Where a shipped file is found writable, or its digest differs from the stamp manifest, the stamp helper returns `None` with the reason `shipped_file_modified:<path>`; it does not fix anything.
- A **new install or update produces a new stamp**; the old stamp's value never reappears for different content.
- **Own and project packs are not stamped and not in the manifest.** Nothing here changes pack loading, discovery, the registry, the model cache or the Runtime. No pin; no wire, schema or store change.
