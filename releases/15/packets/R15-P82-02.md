## Contract

- Step 1: post a `STATUS` with the profile (top 20 by cumulative time and the importer of each module you intend to defer) before changing code.
- Make the named heavy modules load lazily (function-level or `__getattr__` imports) **only where the code path that needs them is exactly the one that triggers the load**. A lazy import must fail the same way and at the same point it would have, so an import error is not hidden. No `try/except ImportError` that swallows a missing module, no stubbed module, no environment-variable switch.
- Behaviour, output, error text and refusal order are unchanged. No pin, no VibeComfy change unless an import in VibeComfy is the only cause; if so, a separate commit and a `READY-PIN` post (never move the pin).
- Import-time test: a subprocess (`python -I -X importtime` or a `sys.modules` probe after running the real `generate` entry up to the point of the first network call, against a fake target) fails when any module on your named list loads. State the list in the test, and keep it short and exact.
