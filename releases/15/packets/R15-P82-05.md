**Route:** S (ChatGPT mode: Pro; [run contract](../../../agent/shared/run-contract.md#chatgpt-session-modes)). It is the proof that the caches admit what a full build admits; the orchestrator reviews it by injecting the failures it must catch.
**Estimate:** 1 day (inferred); about three hours
**Outcome:** One test, over **every** shipped ready template (53 on VibeComfy `c0e910ca`: `template_count: 53` in `template_index.json`, the files `ready_templates/**/*.py` without `_*` and `__init__.py`), proving that the cached path (P82-03's prepared template and P82-04's structural approval) admits **identical bytes and an identical approval** to a full build, including a stale cross-process hit that must rebuild. This is the gate the plan's "nothing stale" rests on.
**Dependencies:** P82-03 and P82-04 merged on `release/15/plan-82` (you may draft against the uncached path before they land; do not post `READY-PROOF` until they have).

## Contract

For each of the 53 templates, with a fixed set of per-request values (at least: the default values, a changed prompt, a changed seed, a changed size where the template has one, a changed model choice where it has one, a seedless rerun), build once through the full path and once through the cached path **in a fresh process** (subprocess, so nothing is shared in memory), and assert byte-equality of: the admitted `workflow.py`, the companion, the API graph, the `api_digest`, the `revision_id` and the invocation receipt's digests. Then, per template, make a stale entry and assert **rebuild, not hit**: the template source changed, the compiler identity changed, provenance changed, the node list changed (a node added or an input renamed), the VibeComfy version string changed, the role plan changed. A stale hit that produces different bytes from a full build must fail the test, and the test must be shown to fail (see Proof). A template that cannot be cached is listed with its reason and runs full, and the test asserts `miss` or `recompute` for it, never a silent skip.

Use the stand-in node list (`plans/81-once-per-command/evidence/installed-container-baseline/standin/standin_lib.py` serves the node schemas for the default entry; for the other templates build the object-info from VibeComfy's own packaged schemas, as `tests/test_v26_canonical_parity.py` and `tools/check_canonical_parity.py` do). Pattern the template loop after `tests/test_v26_canonical_parity.py:11` and `tests/test_templates_module.py`. No parametrization over a hand-written list: iterate `template_index.json` so a 54th template is covered automatically, and assert the count equals `template_count`.

No production change except a test seam that is already in P82-03 and P82-04; **do not add a test-only seam to product code**. If the differential needs one, post `BLOCKED` once naming it. No existing test or fixture changes.

**Pass unchanged:** VibeComfy `tests/test_v26_canonical_parity.py`, `tests/test_templates_module.py`, `tests/test_ready_alias_identity.py`, `tests/test_template_roundtrip.py`, `tests/test_workflow_bundle.py`.

**Mutation check (required in the PR):** show the test **fails** when, in a scratch copy, (a) the key leaves out the node-list digest, (b) the key leaves out the compiler identity, (c) fill writes a stale prompt, (d) the structural approval skips a precondition.
