## Contract

- **The key** is a content digest of: the workflow structure with every value slot masked (graph, not values), the compiler identity, provenance of the workflow source, the VibeComfy version, the role plan, and the digest of the target's node list. Write the key's inputs as one documented, ordered, canonical record and test that changing each input changes the key and that changing a slot value does not.
- **The store** is a directory under the install's data root (find the existing data-root helper; do not invent a path). An entry is written atomically (temp file and rename), carries the key and its inputs, and is read only after the key recomputed from the current inputs equals the entry's key **and** the entry's own content digest checks. Anything else is a **miss**: the command works it out as today, says so in its counters, and rewrites the entry. Deleting the directory only slows the next command. A corrupt, truncated or foreign entry is a miss with a reason, never an exception and never used.
- **Fill per request** renders the prompt, seed, size, `LoadImage` input and the private output prefix from the current request into the kept intermediate. The result is byte-identical to a full build for the same inputs. The attempt-specific save prefix is still rendered every time (`test_seedless_rerun_uses_attempt_specific_save_prefix`).
- **Not cached here:** the approval compile (P82-04), the node-list fetch itself (kept every command; only its digest is an input), model-root hashing, Wan2GP or any other backend. The contract's interface (prepare, key, fill) is written so another backend could implement it; only ComfyUI does.
- No wire, schema or store change; no pin (post `READY-PIN <VibeComfy head>` if VibeComfy code changes; never move the pin). No flag that turns the cache's check off. No broad `except`, no silent fallback, no second code path left as an end state: the full build is the miss path of the same function.
