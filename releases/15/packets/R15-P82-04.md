**Source tasks:** [`plans/82-reuse-across-commands/tasks.md`](../../../plans/82-reuse-across-commands/tasks.md) — RA-2 (second of three packets)
**Route:** S (ChatGPT mode: Pro; [run contract](../../../agent/shared/run-contract.md#chatgpt-session-modes)). Integrity work: the orchestrator reviews it on the high-judgment route and injects the failures it must catch.
**Estimate:** 2 days (inferred); a design STATUS in the first hour, then about three hours to the PR
**Outcome:** The approval compile (`WorkflowBundle.compile`) is split so the **structural** checks run once per structure key and are kept, while slot values, the model-picker rewrite, the projection and the `api_digest` are computed **every request from the exact admitted bytes**. No check is removed, none moves later, and approval is derived from the admitted bytes, never from what was kept. Predicted about 0.3 s *est.* (the second compile) with P82-03's saving.
**Dependencies:** P82-01 (RA-6) and P82-03 (the key and the store) merged on `release/15/plan-82`.

## What the code looks like (scouted 24 November 2026; re-check)

VibeComfy `vibecomfy/workflow_bundle.py`: `WorkflowBundle.compile` (about 2746) runs `_approval_preconditions` (about 2126; the card's 2216 and 2330 are inside it: schema, identity, model gates, lock-pin and reconciliation blockers), then `workflow.compile("api")` (run inputs baked in here), `validate_api_against_schema` and `validate_api_link_shapes`, `materialize_ui`, and builds `ApprovedProjectionRecord` (about 1892) with the `api_digest`. The model-picker `target_model_value` rewrite (about 2787) depends on the attempt's model choice. Agent side: `astrid/packs/vibecomfy/local_server_engine.py` `_approve_live` (215) and `_live_preflight` (73). The [why-each-check table](../../../plans/82-reuse-across-commands/evidence/2026-11-24-why-each-check/README.md) says what each step protects: classes in the target schema, lock-pinned packs or core; lock-pin conflicts; target model spelling; `workflow.py` loads through the capability fence; stale revision. The worker repeats approval after a task is queued; the command-side copy is what refuses **before a task exists**.

Per the scout, structural (cacheable per structure key plus node-list identity): the schema, identity and model gates that depend only on the graph's classes, `validate_api_against_schema` and `validate_api_link_shapes` on the node-class graph, `materialize_ui` (the UI projection does not depend on slot values), and the digest of the graph with slots masked. Per request: `binding_snapshot` and `input_binding`, the slot substitution in `workflow.compile("api", run_inputs=...)`, `api_digest` over the filled projection, the model-picker rewrite, the attempt-scoped `filename_prefix`. **Your STATUS decides the split exactly**; where a check reads a slot value (range, combo membership, type), it stays per request.

## Contract

- The structural part is kept under P82-03's key (extended by the node-list digest), read only after the key recomputes equal and the entry's content digest checks; anything else is a **recompute** with a reason, and approval then runs in full as today.
- `api_digest`, `revision_id`, the projection and every value-dependent check come from the exact admitted bytes on **every** request. `require_canonical_authority` and `_rebind_current_bundle` still run per request, so stale bytes are rejected before the target and before admission (the `test_stale_bundle_rejects_before_target_or_admission` contract).
- A stale structural entry (graph, node list, compiler, provenance, lock pin or VibeComfy version changed since it was kept) is never used. Refusals keep their order and their text.
- The same check order as a full compile for every refusal: a table-driven test lists each refusal in `_approval_preconditions` and shows the cached path produces the same refusal, same order, same message as the full path.
- No wire, schema or store change; no pin (post `READY-PIN <VibeComfy head>`). No flag to turn a check off, no broad `except`, no silent fallback. `WorkflowBundle.compile`'s public signature stays (the Agent's call sites keep working).
