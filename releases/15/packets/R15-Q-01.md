**Source tasks:** `releases/15/qualification.md` row 5 (Lead DECISION r15-lead-qual-0004 on astrid-dev #1834); issue packet, no plan task.
**Route:** X (Extra High): a cross-repository contract with a subtle failure mode; every write path must be driven, and the parser result must be read, not assumed.
**Estimate:** 1 engineering day for phase 1 (the parser). The loader and `start_ms` check are a second packet, R15-Q-03, written after phase 1 shows what the parser sees.
**Repro:** The Release 14 Agent (`c0ad6b54`) wrote transcript association rows `{documentId, mediaId, sourceId}` with no `assetId`; the App requires `assetId` (`timelineBundle.ts:98-104`, a strict object), so `parseTimelineBundle` rejects the bundle and the project cannot open. Failing check to build first: a saved draft from `astrid timelines transcripts refresh` on a fixture, `doc["parent"]["config"]["bundle"]` through `parseTimelineBundle`, must be accepted on `release/15/main` and **must reject** a copy whose association rows lack `assetId` (the harness has to be able to fail).
**Outcome:** A no-network Agent-side test that, for each Agent timeline-writing command on the list below, writes a draft on a fixture and passes the resulting bundle through the App's real `parseTimelineBundle` (run by node from a pinned App checkout), failing the test with the parser's own message when it rejects.
**Dependencies:** none. Needs a sibling astrid-app checkout at a pinned SHA with `node_modules` present (installed once when the sandbox is built; the harness itself must not use the network) and Node with `tsx` (`node --import tsx`; the App's `.nvmrc` is 20.19.4). Fall back on vendoring `src/tools/video-editor/data/typed/timelineBundle.ts` with its SHA and `zod@4.3.6` if the sandbox cannot hold the App checkout.
**Proof:** the new test file passes on `release/15/main`; each case is shown failing against a bundle with the known-bad shape (the packet's own mutation check); the selectors below pass unchanged.
**PR destination:** astrid-agent `p15q/R15-Q-01` → `release/15/q-agent-writes` (cut from `release/15/main` `514499de`), then `release/15/q-agent-writes` → `release/15/main` through the Lead's gate.
**Authority:** [qualification dispatch](../run.md#qualification-dispatch); Lead DECISION r15-lead-qual-0004, -0005 and -0007 on astrid-dev #1834.

## Contract

1. New files only: `tests/editing_conformance/test_agent_writes_open_in_app.py` and `tests/editing_conformance/app_open/open-bundle.mjs` (reads a bundle JSON path, imports the App's `parseTimelineBundle` from `$ASTRID_APP_ROOT`, prints `{"ok": bool, "name": ..., "message": ...}` and exits 0 for accept, 1 for reject). The test skips with a loud, named reason, never silently, if `ASTRID_APP_ROOT` or Node is absent, and a second test asserts the skip is reported as a failure when the environment variable `ASTRID_REQUIRE_APP_PARSER=1` is set (this is how the gate runs it).
2. One case per write below. Each builds a fixture with the repository's own helpers (no network), runs the verb or SDK call, saves the draft (`Checkout.save`, `astrid/sdk/timeline/checkout.py:156`), takes `doc["parent"]["config"]["bundle"]`, and runs the harness. The test blocks outbound network itself (the suite has no global socket block).
3. Writes to cover (SDK names from `astrid/sdk/timeline/commands.py`, CLI verbs from `astrid/packs/timeline/cli*.py`): `occurrence.create`, `clip.move`, `placement.move`, `clip.trim`, `clip.split`, `clip.anchor` (word anchors), `occurrence.add-media`, `clip.add-media`, `occurrence.swap-media`, `clip.swap-media`, `occurrence.duplicate`, `occurrence.fork`, `track.create`, `shot.set`, and the CLI `transcripts refresh` (`cli_working.py:491`; it writes `transcriptReferences` at `:595`). Any other write found in `astrid/packs/timeline` or `astrid/sdk/timeline` is added with a one-line note; the PR states how many writes exist, how many are covered and why any is not (a sweep carries its count).
4. Reuse fixtures: `tests/sdk/test_timeline_sync.py` (`initial_bundle`, `connected`), `tests/editing_conformance/native_word_anchor_fixture.py` (`seed`), `tests/editing_conformance/test_commit_runtime_occurrence_create.py` (`generated_runtime`). No new fixtures that copy these.
5. Report, do not hide, a rejection: a write whose bundle the parser rejects is a **finding for the owning plan**, not a test to loosen. The packet records each in its PR body (command, parser message) and the Qualifier relays it to the plan's board.
