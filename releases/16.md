# Release 16 — Install and update everywhere

**Release:** 16
**State:** Draft

## Highlight

Installing, updating, rolling back and removing Astrid works on Windows, macOS and Linux, and you can see which version you have.

## Intent

A stable version has to survive its own updates. A good outcome: the full install, update, rollback and removal matrix proven on the three systems, one process identity for Agent and Runtime, and releases defined and published from astrid-dev with visible version numbers.

Proposed by the advisor and agreed by Hannah on 15 November 2026 (version 0.1 is "focused on hardening, updates, stability and speed"), with fixes and plans added on the fly from actual usage and user reports. See [Strategy](../strategy.md#decisions).

A stable version must survive its own updates on every system.

## Approach

Finish the update work Release 12 started, then the less common setups. Whether Pinokio is a supported route in version 0.1 is an open owner decision; if not, it is declared unsupported plainly.

Each release has one theme and a [standing lane](../skills/astrid-dev-shared/glossary.md).
