# Release 16 — Install and update everywhere

**Release:** 16
**State:** Draft
**Release manager:** not yet named

## Highlight

Installing, updating, rolling back and removing Astrid works on Windows, macOS and Linux, and you can see which version you have.

## Intent

A stable version has to survive its own updates. A good outcome: the full install, update, rollback and removal matrix proven on the three systems, one process identity for Agent and Runtime, and releases defined and published from astrid-dev with visible version numbers.

Proposed by the advisor and agreed by Hannah on 15 November 2026 (version 0.1 is "focused on hardening, updates, stability and speed"), with fixes and plans added on the fly from actual usage and user reports. See [Strategy](../strategy.md#decisions).

A stable version must survive its own updates on every system.

## Approach

Finish the update work Release 12 started, then the less common setups. Whether Pinokio is a supported route in version 0.1 is an open owner decision; if not, it is declared unsupported plainly.

Each release has one theme and a [standing lane](../skills/shared/glossary.md).

## Included plans

- [Plan 29](../plans/29-update-and-release/plan.md) — the remainder of one update path.
- [Plan 30](../plans/30-update-everywhere/plan.md) — less common setups.
- [Plan 09](../plans/09-install-and-update-confidence/plan.md) — hosted tests for install, update, rollback and removal.
- [Plan 38](../plans/38-one-process-identity/plan.md) — one process identity across systems.
- [Plan 31](../plans/31-releases-from-astrid-dev/plan.md) — releases and version numbers from astrid-dev.
- [Plan 75](../plans/75-fast-saving/plan.md) — one acceptor, the save-speed lead (owner's decision, 23 November 2026): a save costs the change, not the history, after Plan 89's Release 15 measurement.
- [Plan 63](../plans/63-dependable-saving/plan.md) — dependable saving: nothing is refused or undone however fast the owner edits, and every change from the editor or an agent ends in one of four outcomes the server names (about 39.5 days; moved from Release 15 by the owner on 23 November 2026; starts on her go).
- [Plan 76](../plans/76-editing-together/plan.md) — editing together, after Plan 63: an agent edits beside a person without blocking or overwriting them (about 12 days; moved from Release 15 on 23 November 2026).
- [Plan 18](../plans/18-timeline-editing/plan.md) — phase A only, agents and packs (about 18 days, Agent and Runtime, no App code), after Plan 63's server track; phase B waits on its D4 (moved from Release 15 on 23 November 2026).
- [Plan 39](../plans/39-green-mains/plan.md) — the structural fixes from Release 12, and the release rule that every required check is green on each pinned commit (moved from Release 15 on 23 November 2026).
- [Plan 50](../plans/50-recorded-boundaries/plan.md) — rented-machine failures found on a CPU (moved from Release 15 on 23 November 2026).
- [Plan 92](../plans/92-generate-within-a-second/plan.md) — generate within a second: `astrid generate` queued in under 1 s through a resident host and thin client, after Plan 82's caches (about 5 to 6 days; owner, 24 November 2026).
