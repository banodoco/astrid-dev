# R14-P55-09 — VibeComfy reuses a resident session across jobs

**Source task:** [Plan 55, LS-15](../../../plans/55-local-speed/tasks.md)  
**Estimate:** 3 human engineering days, derived from the pack integration and concurrency proof. The row gives no day count.  
**Outcome:** The first job for a key takes the full preparation path. Later jobs reuse the resident pack's catalogue, placements, prepared templates and held ComfyUI sessions. On managed ComfyUI, audits, node restore, dependency sync and doctor run again when their generation changes. Each job gets its own environment, cancellation context and output prefix. The supervisor owns process signals. See [design §1](https://github.com/banodoco/astrid-dev/blob/8c8dddea93fea56d81ffd41e67887dc63c018ffa/plans/55-local-speed/design.md#1-the-fast-lane-key-and-what-the-first-job-leaves-behind) and [§4](https://github.com/banodoco/astrid-dev/blob/8c8dddea93fea56d81ffd41e67887dc63c018ffa/plans/55-local-speed/design.md#4-resident-helper-lifetime-state-and-isolation).  
**Dependencies:** All merged into `release/14/plan-55`. LS-4 supplied prepared templates ([Agent #385](https://github.com/banodoco/astrid-agent/pull/385), [VibeComfy #175](https://github.com/banodoco/VibeComfy/pull/175)), LS-5 supplied held connections ([Agent #371](https://github.com/banodoco/astrid-agent/pull/371)), and LS-8 supplied the resident worker ([Agent #405](https://github.com/banodoco/astrid-agent/pull/405), `d0217776`).
