### App decision

- [updateOperation.ts:151](https://github.com/banodoco/astrid-app/blob/3b3c85fdae7592cd74e2a87a702167f67879b162/src/shared/lib/updates/updateOperation.ts#L151) reads Runtime **health** and installer **status** in parallel. The transition uses health’s `runtime_instance_id` and the installed release derived from health; the installer status response supplies operation state separately. A status-read failure does not by itself prevent the release check.
- [updateStatus.ts:32](https://github.com/banodoco/astrid-app/blob/3b3c85fdae7592cd74e2a87a702167f67879b162/src/shared/lib/updates/updateStatus.ts#L32) derives the installed release with `installedReleaseOf(health)`, falling back to `0` if absent. [installedRelease.ts:15](https://github.com/banodoco/astrid-app/blob/3b3c85fdae7592cd74e2a87a702167f67879b162/src/shared/lib/updates/installedRelease.ts#L15) reads the validated health object’s top-level `release`.
- [liveUpdate.ts:41](https://github.com/banodoco/astrid-app/blob/3b3c85fdae7592cd74e2a87a702167f67879b162/src/shared/lib/updates/liveUpdate.ts#L41) compares each valid observation with the **last observation stored in that tab’s sessionStorage**, then replaces it. It generates the notice only if the instance differs and the release is higher; the notice lasts eight seconds. It is not necessarily a fixed value captured at page load.
- If the tab has no prior valid observation—for example, it first observes the new instance after replacement—it stores the new pair without a transition. The same instance ID with a higher release also produces no transition and replaces the stored pair. A missing or empty instance ID causes `noteRelease` to return without storing that observation. The failed artifact does not reveal which, if any, occurred.
- [resolveUpdate.ts:147](https://github.com/banodoco/astrid-app/blob/3b3c85fdae7592cd74e2a87a702167f67879b162/src/shared/lib/updates/resolveUpdate.ts#L147) selects the required-update card when the installed release is below the required release; [QuietUpdateNotice.tsx:19](https://github.com/banodoco/astrid-app/blob/3b3c85fdae7592cd74e2a87a702167f67879b162/src/shared/components/RuntimeConnection/QuietUpdateNotice.tsx#L19) separately renders the brief transition notice. The Settings result and Reload button can arise from terminal operation state, so they do not prove the release-transition comparison succeeded.
