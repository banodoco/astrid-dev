**App decision at `adad82f`.** The hosted update observer reads health and installer status in parallel, but calls `noteRelease` using the **health** response’s Runtime instance ID and installed release; installer status supplies operation state separately ([updateOperation.ts:151](https://github.com/banodoco/astrid-app/blob/adad82f07cf35007f96fa44adea9211a09117391/src/shared/lib/updates/updateOperation.ts#L151)). The installer observer refreshes immediately when monitoring starts and then every three seconds, subject to its connection and monitoring conditions ([useInstallerUpdate.ts:48](https://github.com/banodoco/astrid-app/blob/adad82f07cf35007f96fa44adea9211a09117391/src/shared/hooks/useInstallerUpdate.ts#L48)).

For the intended notice, a validated health response must supply the **new nonempty instance ID and higher release** while session storage still holds the old pair. [liveUpdate.ts:37](https://github.com/banodoco/astrid-app/blob/adad82f07cf35007f96fa44adea9211a09117391/src/shared/lib/updates/liveUpdate.ts#L37) stores each nonempty-instance observation and produces the eight-second notice only when the instance differs and release increases. An empty instance returns without replacing storage; a failed or rejected health read does not call `noteRelease`. Installer status alone cannot replace the observation.

A partial health response is different: the health validation permits an absent release, and the installed-release logic falls back to `0` ([client.ts:267](https://github.com/banodoco/astrid-app/blob/adad82f07cf35007f96fa44adea9211a09117391/src/shared/lib/runtime/client.ts#L267), [updateStatus.ts:32](https://github.com/banodoco/astrid-app/blob/adad82f07cf35007f96fa44adea9211a09117391/src/shared/lib/updates/updateStatus.ts#L32)). If such a response carries the **new** nonempty ID, it can replace the old pair with new-ID/0; a subsequent new-ID/14 response has the same instance and produces no transition. A valid stale old response can also replace a newer pair. No saved response shows either case occurred.
