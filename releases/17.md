# Release 17 — Version 0.1, the stable release

**Release:** 17
**State:** Draft
**Kind:** minor

## Highlight

Version 0.1: Astrid installs, updates and generates quickly and dependably on Windows, macOS and Linux, with every test green.

## Intent

The first version to call stable. Version 0.1 is focused on hardening, updates, stability and speed (Hannah, 15 November 2026): what already exists, made fast and dependable, not new capability. A good outcome: testers run install, update and generation unaided on the three systems, every test is green, and the documentation takes a new person from purpose to a first result.

Hardening only, once speed, stability and updates are in; this release carries version 0.1.

## Approach

Hardening only: no new features. It follows local speed ([Release 14](14.md)), stability ([Release 15](15.md)) and install and update everywhere ([Release 16](16.md)). Fix what the tester runs find, finish the documentation, and declare honestly what is not supported. Open owner decisions: whether rented machines are fully supported in 0.1 or labelled experimental with their money-safety fixes done, and whether Pinokio is a supported install route.

Each release has one theme, plus a standing lane for fixes and small plans that come from actual usage and user reports. What comes after is version 0.2, which is open: see [Strategy](../strategy.md#versions).
