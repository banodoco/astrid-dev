# Release 17 — Continuous hardening

**Release:** 17
**State:** Draft
**Kind:** patch
**Release manager:** not yet named

## Highlight

The Agent, Runtime and App have trustworthy green test suites, execution failures are reproducible without paid machines, and the execution host is simpler to maintain.

## Intent

After [Release 16](16.md), make reliability sustainable: eliminate inherited CI failures by cause, keep checks green and reduce the execution host's structural risk. Owner direction, 25 November 2026. This is the first planned patch in the 0.1 series (0.1.1 if there is no intervening patch), on the path to 0.2; do not defer harm on supported Release 16 journeys merely because it appears in this hardening backlog.

## Approach

Preserve Plan 91's existing branch, evidence, mailbox and standing rulings; the Lead must coordinate its move from the old Release 16 target before any landing or new target-dependent dispatch. Run 39 and 91 with explicit per-test baselines and root-cause repair; never weaken current-behavior assertions. Reconcile 50 against RunPod's experimental status, with money safety required already. Start the host extraction with 13, use its measured result to bound 83, and coordinate with the process-identity work in 16 and test owners so proof is not invalidated. Include VibeComfy/launcher required checks where they affect the shipping tuple, without inventing a new independent programme. Plan 107 (owner direction, 28 November 2026) executes the pass list that Release 16's H3 extension contract reserves. It builds on the Release 16 H3 programme and does not change that programme's single-pass guarantees. It is a creative addition inside a hardening release, so the Lead schedules it after the green and host work it shares Agent CI with. Ship the integrated set once the promised green and hardening outcomes are proven. [Release 18](18.md) follows.

Each release has one theme and a [standing lane](../agent/shared/glossary.md).

Plan 107 runs in the H3 lane, with Plans 66, 68, 70 and 67 in Release 16: [lane brief](16/briefs/h3.md).
