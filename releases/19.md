# Release 19 — Version 0.1, the stable release

**Release:** 19
**State:** Draft
**Kind:** minor
**Release manager:** not yet named

## Highlight

Version 0.1: Astrid installs, updates and supports dependable, fast creative work on Windows, macOS and Linux, with the supported Pinokio route and green required tests.

## Intent

Preserve the previously planned stable milestone (formerly Release 17) after the revised sequence: [16 — Dependable](16.md), [17 — Continuous hardening](17.md), [18 — Fluid and powerful](18.md). The first stable release is focused on hardening, updates, stability and speed, with documentation taking a new person from purpose to a first result.

## Approach

Qualification and documentation, not a new feature programme. Have testers run install, update, generation and creative work unaided on the supported configurations. Use exact final release evidence; fix regressions and declare limits honestly. Pinokio is supported, RunPod is experimental with money-safety controls. The previous minor milestone is preserved here as a provisional placement, not a new publication authorization or a decision to commit every later capability to v0.1. Version 0.2 remains open; see [Strategy](../strategy.md#versions).

Each release has one theme and a [standing lane](../skills/shared/glossary.md).
