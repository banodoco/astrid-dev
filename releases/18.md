# Release 18 — Make Astrid fluid and powerful

**Release:** 18
**State:** Draft
**Release manager:** not yet named

## Highlight

Astrid feels responsive, enables smooth human-agent collaboration and makes generation and creative operations easier to express and extend.

## Intent

Build on the dependable product and the hardening release. Owner direction, 25 November 2026: move the remaining speed, collaboration, extensibility and media-efficiency projects here, and include timeline responsiveness and generation destination.

## Approach

Re-measure the installed Release 17 product using Plan 85's method. Sequence Plan 75 after the dependable-save base; build 76 and 18 Phase A on that contract, sharing proof and avoiding a parallel editing representation. Plan 80 follows Plan 79: filesystem cloning first, then explicitly resolve the linked-media authority and migration decisions before extending the phase. Plan 92 builds on Plan 82 and the lifecycle/custody work; Plan 37 uses the same generation and timeline command boundaries. Plan 86 measures real interaction latency and fixes the largest costs, not just save acceptance. The exact sequence and phase boundaries remain subject to this release's later scoping, and no listed plan is authorized to start. Ship as one integrated release, then qualify v0.1 in [Release 19](19.md).

Each release has one theme and a [standing lane](../skills/shared/glossary.md).

## Included plans

- [Plan 75](../plans/75-fast-saving/plan.md) — One acceptor: fast, history-independent commit acceptance, target 300 ms median; reconcile after Release 16.
- [Plan 76](../plans/76-editing-together/plan.md) — Fluid simultaneous editing with unrelated changes landing, in-place adoption, clear notices and conflict recovery.
- [Plan 18](../plans/18-timeline-editing/plan.md) — Phase A: discoverable extensible agent and pack editing operations on the dependable commit foundation; later editor gestures remain a separate scope decision.
- [Plan 92](../plans/92-generate-within-a-second/plan.md) — Queue a warm generation within a second through a resident host and verified current cached results.
- [Plan 80](../plans/80-use-media-in-place/plan.md) — Use local footage without unnecessary copies: clone first; true linked-media phases remain subject to the recorded custody and portability review.
- [Plan 86](../plans/86-the-timeline-feels-fast/plan.md) — Measure and improve actual editor responsiveness: seek, scrub, play, drag, open and related everyday interactions.
- [Plan 37](../plans/37-generate-time-destination/plan.md) — State generation variant, promotion and timeline destination in the initial request; preserve the output if placement fails.
