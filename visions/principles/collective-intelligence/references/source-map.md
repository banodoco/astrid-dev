## Design implications, not implemented claims

A generalizable contribution format needs source custody, author attribution, immutable revisions, evidence pins, reviewer/editor decisions and scope (including private/public visibility). Agent retrieval should be treated as **untrusted evidence-bearing data**: it can inform an answer, prompt or workflow proposal, but cannot override system instructions or independently authorize actions.

A possible first test is retrieving a precise technique from Hivemind for a known model/environment, examining its source and revision, applying it through an already approved Astrid capability, and offering a *proposed* contribution back with user permission. This separates knowledge quality, capability execution and editorial acceptance.
