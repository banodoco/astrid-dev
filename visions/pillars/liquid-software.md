# Pillar 2 — Agent-Powered Liquid Software

**Tools should adapt to the work as people and agents create, rather than force creative work into fixed interfaces.**

Excellent, opinionated tools should be assembled from reusable components and capabilities. Users and agents can arrange, bind, extend and reconfigure those tools while working—physically (dock, float, nest, spatially place) and functionally (share timelines, resources and context). Packs can contribute both agent actions and human-facing interfaces, with consistent underlying operations.

The aim is a **responsive creative environment** that can change from a conventional editor to more spatial ways of working, not a generic blank canvas or an excuse to rebuild existing foundations.
