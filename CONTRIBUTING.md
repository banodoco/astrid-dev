# Contributing to Astrid

**Everyone can contribute.** Start with the [contributor workflow](docs/contribution-workflow.md), or give your agent [the Astrid development skill](skills/astrid-dev/SKILL.md).

- [Find an issue](https://github.com/banodoco/astrid-dev/issues) for bugs and small improvements, or [browse projects](plans/index.md) for a substantial independent outcome.
- [Claim an available project](docs/contribution-workflow.md#claim-a-project-without-waiting-for-a-maintainer), [propose new scope](https://github.com/banodoco/astrid-dev/issues/new?template=project-proposal.md), or [ask a project question](https://github.com/banodoco/astrid-dev/issues/new?template=project-question.md).
- Submit code in the owning product repository and link actual checks; a multi-repo project finishes with one [integrated completion review](docs/contribution-workflow.md#submit-a-completed-project).

**Ownership isn't execution authority.** We aim for easy participation, sound decisions and independently verifiable results.
